- **2023.06 三套音频**：第 2、3 套 SHA-1 完全相同（`57c53b2e12b1…`），只保留 1、2 两段，避免重复 17 MB。

- **2023.03 两版音频**：`四级真题（3套相同）听力音频.mp3`（16.9 MB）与 `四级听力全1套.mp3`（23.3 MB）时长一致，取 128 kbps 的后者。

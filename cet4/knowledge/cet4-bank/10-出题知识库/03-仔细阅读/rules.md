# 仔细阅读（Section C）出题知识库

| 项 | 实测 |
|---|---|
| 题量 | 每篇 5 题，46–50 / 51–55 |
| 题型 | 细节 58%、态度 22%、推断 10%、原因 9% |
| 题干 | What 占 83%，平均 11.3 词，最长 17 |
| 答案 | A31/B29/C30/D30，接近均匀 |
| 选项 | 正确项 9.3 词、干扰项 9.4 词，四项等长 |
| 正确项 | 与原文连续实词重合中位 3；≥6 视为照抄 |
| 干扰项 | 无中生有 / 偷换概念 / 因果倒置 / 范围扩大 |

## 出题规则

1. 先定 5 个考点句（转折/研究/因果/比较/态度），按原文顺序排 46–50；
2. 题干 ≤15 词，What 为主；
3. 正确项：保留主题名词、替换谓语，连续实词 ≤4；
4. 三个干扰项三种手法各一，禁止双答案；
5. 选项长度差 ≤3 词，答案覆盖 ≥3 个字母；
6. 术语按真题体例随文加注（如 hippocampus 海马体）。

## 🚀 终端全真模拟器使用指南

项目提供了开箱即用的交互式终端刷题模拟器：`bin/cet4_simulator.py`。

### 1. 交互式主菜单启动
```bash
python bin/cet4_simulator.py
```
- 控制台将列出全部 28 套试卷的主题与篇名。
- 输入天数编号（例如 `1` 到 `28`，直接回车默认第 1 天）即可进入限时全真考场。

### 2. 查看题库完整目录
```bash
python bin/cet4_simulator.py --list
```

### 3. 直接进入指定天数模考
```bash
python bin/cet4_simulator.py --day 15
```

### 4. 🧠 艾宾浩斯科学遗忘曲线调度命令
```bash
# 查看指定天数（如第 1 天）的“今日新学 + 今日必复习”精确任务清单与 3 步极速复习法
python bin/cet4_simulator.py --today 1

# 查看前四周 (28天) 完整的艾宾浩斯遗忘曲线复习矩阵大表
python bin/cet4_simulator.py --schedule
```

### 5. 模拟器主要功能特性
1. **真实限时倒计时**：建议耗时 10 分钟，自动统计实际作答秒数。
2. **四级标准判分体系**：仔细阅读每题 14.2 分，单篇满分 71.0 分（及格基准线 42.6 分，优秀线 56.8 分）。
3. **错题名师陷阱诊断**：明确标出每一道题的正确答案、定位原文句与强干扰项陷阱设计。
4. **逐段地道精翻**：完成作答后支持一键展开全文对照翻译。
5. **核心考点词库速查**：每篇配套 10 个四级核心考点词，附带国际音标（IPA）、精确词性、真题语境释义及高频搭配。

## 🏮 双引擎地毯式精读宝典（字下直译 + 无术语视觉句构）

针对词汇薄弱、抗拒枯燥语法术语的学习者，试卷（Week 1 率先落地）内置创新性“字下直译与视觉结构图”：

1. **单词正下方直译**：放弃查词字典跳转，在每个英文单词正下方精确对齐其中文含义，杜绝生词卡顿。
2. **零术语直观解构**：彻底告别“主谓宾定状补倒装”等抽象术语，采用直觉化视觉符号：
   - `⭕ 主角`：这句话核心在说谁 / 什么东西
   - `══ 核心动作 ══`：主角干了什么事 / 处于什么状态
   - `~~ 承受对象 ~~`：动作波及的目标或对象
   - `( 辅助配菜 )`：时间、地点、原因、修饰等背景调味料
3. **做题雷达精准映射**：明确标出该句对应哪一道题（如 `🎯 对应第 1 题定位句`），指出出题人如何在此设伏。

## 🧠 艾宾浩斯科学记忆遗忘曲线复习规划

人类大脑在记忆新信息后，遗忘速度先快后慢。为彻底打破“学了后面忘前面”的恶性循环，本系统内置**科学抗遗忘复习矩阵**：

### 1. 五大复习临界周期
- **第 1 天后（1d）**：初次巩固，阻断 60% 初始遗忘
- **第 2 天后（2d）**：隔日强化，建立海马体短时突触
- **第 4 天后（4d）**：周期对抗，进入稳定记忆区
- **第 7 天后（7d）**：周度复盘，跨越短时记忆向长时记忆过渡
- **第 15 天后（15d）**：半月长效，形成大脑皮层永久神经通路

### 2. 每日时间投资（每天仅需 20~25 分钟）
- **新课新做（约 15 分钟）**：10 分钟做题判分 + 5 分钟精读错题。
- **旧课复习（仅 5~10 分钟）**：根据 `--today <天数>` 自动列出的 1~4 篇旧文章，采用 **3 步极速复习法**：
  1. **遮住中文看英文（30秒）**：遮住考点词表中文，快速过一遍 10 个生词；
  2. **回看错题图解（1分钟）**：翻看做错题目对应的【句子图解】与【做题雷达】，巩固破题直觉；
  3. **大声朗读金句（1分钟）**：挑出 1 句带感句子顺畅朗读，激活口腔与听觉记忆。

## 💡 科学备考与复盘建议（SOP）

1. **第 1 遍（全真模考，限时 10 分钟）**：
   - 使用 `python bin/cet4_simulator.py --day X` 或直接阅读 Markdown 试卷（不展开折叠部分）。
   - 训练先扫题干抓定位词、再回文寻读、最后比对同义替换的实战技巧。
2. **第 2 遍（复盘诊断，分析错因）**：
   - 展开试卷底部的答案解析，仔细比对做错题目的干扰项（是“偷换概念”、“因果倒置”、“范围扩大”还是“无中生有”）。
3. **第 3 遍（双引擎精读，内化词汇）**：
   - 展开【🏮 双引擎地毯式精读宝典】，通过单词正下方的中文对照扫除每个词的盲区，观察视觉句构图。
4. **第 4 遍（艾宾浩斯循环复习）**：
   - 每天做新题前运行 `python bin/cet4_simulator.py --today <天数>`，花 5~10 分钟完成当天抗遗忘复习清单。

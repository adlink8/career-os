## 1. 产线（按顺序执行）

| 步 | 命令 | 作用 |
|---|---|---|
| 1 取源 | `python cet4/bin/cet4_daily_fetch.py --top 24 --ignore-state --out cet4/var/cet4-daily/out_v5` | 抓外刊（BBC / Guardian / ScienceDaily / The Conversation），保留原文、URL、来源 |
| 2 改写 | `python cet4/bin/cet4_adapt_v5.py --src cet4/var/cet4-daily/out_v5/candidates-<date>.json --n 7 --start 81` | 只取**说明文**源，中等幅度改写（保解释顺序、词汇下沉、删枝蔓），产出正文 + 5 题 |
| 3 修硬伤 | `python cet4/bin/cet4_scrub.py --glob "set-8[1-7].json"` | 修四类：证据链悬空、拼接接缝、原地打转、结尾落点 |
| 4 审查 | `python cet4/bin/cet4_chain_v5.py --glob "set-8[1-7].s1.json"` | 独立审查 → must_fix 回灌修复 → 复审 → 盲做，一条命令跑完 |
| 5 出卷 | `python cet4/bin/cet4_build_paper.py var/cet4-daily/<paper>.json --mode explain|plain` | 渲染讲解版/纯题版 HTML（含音频、逐句解析、词典） |

可选：`cet4_fix_roles.py`（补成分标签）、`cet4_route_notes.py`（补路标）、`cet4_listen_stems.py`（听力题干）、`cet4_audio_assemble.py`（真人感停顿/换气）。

## 2. 验证（三道尺子，全部要跑）

| 尺子 | 脚本 | 判读方式 |
|---|---|---|
| 答案一致性 | `cet4_chain_v5.py` 内的盲做 | 模拟稿必须与真卷基线（99.2%）持平；出现不符就是答案或题目有问题 |
| 读者层面真题感 | `cet4_authenticity.py` | 与**真卷均值**比，不比绝对分；≥ 真卷均值即达标 |
| 专家审查 | `cet4_chain_v5.py` 的 review | 必须与**真卷基线**比：真卷在同一审查员下 0/8 通过，所以模拟 1/7 已属不低 |

**禁止**把任何一项做成脚本门禁（阈值判 PASS/FAIL）；只报数，判定由审查员 verdict 决定。

## 4. 已知边界（不要自欺）

- **对抗式鉴伪过不了**：把模拟稿和真题原文混在一起让判据二选一，模拟稿 0/30+ 全部被认出。
- 对照实验证明这是**口径问题**：人类写的 ScienceDaily 原文只删不改，也被判「模拟」5/5；真题改写版在不同轮次被判「改写」和「原样」。
  即对抗判据实际在测「这段文字我是否见过 / 是否真题体裁」，不是「是否机器写的」。
- 读者层面「分不出来」已经成立（4.11 vs 3.10，86% 达 ≥4 分）；论文层面请按第 2 节三道尺子判定。

## 7. Part II 听力（2026-11-05）

产线：`cet4_listening.py`，四阶段
1. `--stage script`：按真题结构出 8 段（A 新闻 3 段 7 题 / B 长对话 2 段 8 题 / C 短文 3 段 10 题），共 25 题
2. `--stage tts`：逐句合成，对话按脚本里的 `M:`/`W:` 自动切男女声（Guy / Aria），句间 0.30s、换人 0.62s 停顿 + 换气
3. `--stage directions`：Section A/B/C 标准指令音（各约 20s）拼到每节首段前
4. `--stage qaudio`：每题题干合成后追加到音轨末尾，每题后留 12s 答题停顿（真题做法：题目不印卷面）

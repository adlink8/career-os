# 四级仔细阅读：真题出题规律与出题老师工作规范

> 数据来源：`cet4/knowledge/cet4-bank/01-历年真题-Markdown` 21 套 Section C，共 **120 道题**（46–55）。
> 统计脚本：`cet4/bin/cet4_question_stats.py`；范例库：`cet4/var/cet4-daily/exemplars.json`（120 条，供出题老师模仿）。

## 一、120 道真题的硬统计

| 指标 | 实测 | 对出题的含义 |
|---|---|---|
| 题型配比 | 细节 70（58%）、态度 27（22%）、推断 12（10%）、原因 11（9%） | 一套 5 题：细节 2–3、态度 1、推断 1、原因/词义 1；**不要 5 题全是细节** |
| 题干首词 | What 100（83%）、Why 11、How 7、When 1 | 题干以 What 为主，Why 只用于因果考点 |
| 题干长度 | 平均 11.3 词，最长 17 词 | 题干超过 17 词就是加戏 |
| 答案分布 | A 31 / B 29 / C 30 / D 30 | **必须接近均匀**；5 题至少覆盖 4 个字母更稳 |
| 选项长度 | 正确项 9.3 词，干扰项 9.4 词 | 四项长度差 ≤3 词，禁止“最长即答案” |
| 正确项与原文连续实词重合 | 均值 3.7，中位 3；≤3 占 58%，≥6 占 26% | 允许主题名词重合，**连续实词 ≥6 视为照抄**；正确项靠同义替换谓语与结构 |
| 含绝对化词的干扰项 | 15/120（12.5%） | 绝对化（all/never/only/must）只能偶尔用，不能题题用 |
| 正确项实词完全不在原文 | 仅 2 题 | 完全“无中生有”的正确项几乎不存在；正确项必须能在原文找到依据 |

## 二、题干逻辑：先有考点，再有一句话

真题不是“读完文章随便问”，而是**先锁定一个可考句，再把它变成一个疑问**。可考句只有五类：

| 考点句 | 标志 | 题干模板 |
|---|---|---|
| 转折 | but / however / rather / yet / instead | What can we learn from …? / What does the author say about …? |
| 研究结论 | study found / researchers report / according to | What did the study find about …? |
| 因果 | because / so / therefore / lead to | Why does …? / What may account for …? |
| 比较/极端 | more than / only / first / far less | What is said to be …? |
| 观点态度 | argue / believe / suggest / should | What does the author think of …? |

**顺序铁律**：5 道题必须按它们在原文出现的先后排列（Q46 的定位句在 Q47 之前）。真题 120 题里没有倒序。

## 三、选项逻辑：三个干扰项各有“犯罪手法”

| 干扰项类型 | 做法 | 例子（真题风格） |
|---|---|---|
| 无中生有 | 原文没有的主体/比较/因果 | 原文只说“记忆重叠”，选项说“海马体被抑制” |
| 偷换概念 | 换主语、换对象、换范围 | 原文 “the lines between experiences”，选项换成 “between places” |
| 因果倒置 | 把结果写成原因，或反向 | 原文 “faster reaction 导致 accuracy 下降”，选项说“accuracy 下降导致反应更快” |
| 范围扩大/绝对化 | some→all、may→is、often→always | 原文 “may sound like a false alarm”，选项 “is a threat” |

**正确项写法**：保留原文主题名词（便于定位），替换谓语/结构（同义表达），长度与干扰项持平。  
**禁止**：正确项整句照搬原文；三个干扰项都用同一种手法；两个选项都能被原文支持（双答案）。

## 四、出题老师需要什么（工作流）

```
输入：文章 + 5 个考点候选句（转折/研究/因果/比较/态度）
1. 选 5 个考点，按原文顺序排成 46–50
2. 每个考点定题型（细节/态度/推断/原因），写题干（≤15 词，What 开头为主）
3. 写正确项：同义替换谓语，保留主题名词，长度 ≈9 词
4. 造 3 个干扰项：分别用无中生有 / 偷换概念 / 范围扩大，长度与正确项差 ≤3 词
5. 自检：答案字母分布、有无双答案、定位句是否逐字在原文、5 题是否按顺序
```

## 五、四级大纲对阅读的要求（通行口径）

| 项 | 要求 |
|---|---|
| 分值/时间 | 阅读 35%（248.5 分），40 分钟 |
| 题型 | 选词填空 10 题（5%）、长篇匹配 10 题（10%）、仔细阅读 10 题（20%） |
| 仔细阅读篇幅 | 每篇约 300–400 词，2 篇 |
| 词汇 | 约 4500–4700 词，允许 3% 超纲词（不影响答题） |
| 技能 | 主旨大意、重要细节、推理判断、词义猜测、观点态度、篇章结构 |
| 语速/阅读速度 | 阅读约 70–80 词/分钟 |

**对模拟题的含义**：文章 350±50 词、5 题、题文同序、答案均匀、选项等长、至少 1 题考转折、至少 1 题考同义替换——这些是硬约束，不是建议。

## 六、给 CodeBuddy 出题老师的注入规范（已写入 prompt）

1. 先给 5 条同题型真题范例（题干+四选项+答案），再动笔；
2. 题号固定 46–50，按原文顺序出题；
3. 正确项连续实词与原文重合 ≤4；谓语必须换说法；禁止整句照搬；
4. 干扰项三种手法各至少一个；禁止双答案；
5. 选项长度差 ≤3 词，正确项不得总是最长；
6. 答案字母至少覆盖 3 个，尽量 4 个；
7. 自检通过后交付，审查以 CB 审查 verdict 为准（脚本只做冒烟）。

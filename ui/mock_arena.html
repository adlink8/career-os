第 1 题: 在 MySQL/SQLite 复合索引 (a, b, c) 中，下列哪个 WHERE 查询语句【无法完全利用】索引的全部字段？
A. WHERE a = 1 AND b = 2 AND c = 3
B. WHERE a = 1 AND b > 2 AND c = 3 (最左前缀范围查询失效)
C. WHERE a = 1 AND c = 3
D. WHERE a = 1 AND b = 2 ORDER BY c
💡 答案解析：最左前缀原则中，遇到范围查询（>、<、BETWEEN）后，后续字段将无法利用索引进行等值匹配（B中c字段退化为索引下推过滤）。
💻 【高频手撕真题】: 最长无重复字符子串长度 (LeetCode 3 / 大厂常考)
def length_of_longest_substring(s: str) -> int: char_set = set() left = 0 max_len = 0 for right in range(len(s)): while s[right] in char_set: char_set.remove(s[left]) left += 1 char_set.add(s[right]) max_len = max(max_len, right - left + 1) return max_len

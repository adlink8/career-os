personal_system.sqlite
personal_system.sqlite (不可变证据库)
D:/ADLINK/数据分析/var/db/personal_system.sqlite
承载全系统 14,031 条证据链的核心物理存储。通过注入不可变 SQLite 触发器（BEFORE UPDATE/DELETE ABORT），在物理层杜绝一切历史数据篡改。
💡 架构价值与面试破局话术:
“在传统的软件设计中，数据防篡改常写在应用层。我在数据库引擎物理层挂载了不可变触发器，任何尝试修改或删除历史证据的操作都会被底层引擎原子阻断并抛出异常，从根源上保障了数据的不可篡改性。”
⚙️ 底层真实实现代码 / SQL:
-- 不可变触发器注入 CREATE TRIGGER IF NOT EXISTS trg_prevent_evidence_update BEFORE UPDATE ON knowledge_unit_evidence BEGIN SELECT RAISE(ABORT, 'CRITICAL: Evidence history is immutable!'); END;

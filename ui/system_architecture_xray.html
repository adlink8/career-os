Layer 3 · 核心湖仓

不可变触发器 (SQLite Immutable Triggers)

在底层物理数据库中通过 CREATE TRIGGER 注入禁止 UPDATE 和 DELETE 逻辑，确保已清洗数据在历史流转中具备 100% 防篡改特性。

架构价值与面试破局话术:

“在传统的应用层校验中，代码 Bug 很容易误改历史记录。我在 SQLite 存储层设计了不可变触发器，任何非法的写操作都会在数据库引擎内部被原子截断，保障了数据治理的严肃性。”

底层真实代码 / 规则逻辑: Physical Verified 
-- 1. 物理层防篡改触发器
CREATE TRIGGER IF NOT EXISTS trg_prevent_evidence_update
BEFORE UPDATE ON knowledge_unit_evidence
BEGIN
    SELECT RAISE(ABORT, 'CRITICAL: Evidence history is immutable!');
END;

CREATE TRIGGER IF NOT EXISTS trg_prevent_evidence_delete
BEFORE DELETE ON knowledge_unit_evidence
BEGIN
    SELECT RAISE(ABORT, 'CRITICAL: Evidence history cannot be deleted!');
END;

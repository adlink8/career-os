# 求职实操完全手册 —— 协议、权益、签约、入职全指南

> 整理时间：2026-08-04  
> 适用对象：全日制本科计算机相关专业 2027 届应届毕业生  
> 说明：按「签协议前 → 秋招中 → 实习期 → 入职后」时间线组织，去重合并自多份原始文档

## 一、核心红线速查

记住这三条，守住就不会踩大坑：

| 红线 | 为什么重要 | 违反后果 |
|------|-----------|----------|
| **实习期间不缴社保** | 缴社保 = 失去应届生身份 | 考公/考编/部分校招资格作废 |
| **只签实习协议，不签劳动合同** | 劳动合同 = 缴社保 = 同上 | 同上 |
| **所有承诺写进协议** | 口头承诺无法律效力 | 被口头忽悠后无法维权 |

> 应届生身份保留的**唯一标准**是：**是否缴纳社保**。签实习协议、签三方协议，都不等于就业；只有签了劳动合同+缴了社保，才算就业。

## 二、协议类型完全对照表

### 2.1 核心结论速查

| 协议/合同 | 法律性质 | 签订时间 | 是否影响应届生身份 | 是否有社保 |
|-----------|----------|----------|-------------------|-----------|
| **实习协议** | 民事合同 | 在校期间 | ❌ 不影响 | ❌ 不缴 |
| **三方协议（就业协议书）** | 民事合同（意向书） | 毕业前 | ❌ 不影响 | ❌ 不缴 |
| **劳动合同** | 劳动法约束 | 毕业后正式入职 | ✅ 影响 | ✅ 缴纳 |
| **劳务合同** | 民事合同 | 随时 | ❌ 不影响 | ❌ 不缴 |
| **保密协议/竞业协议** | 民事合同附件 | 入职前/入职时 | ❌ 不影响 | — |

### 2.2 实习协议（在校生实习时签）

| 维度 | 说明 |
|------|------|
| **法律性质** | 民事合同，受《民法典》约束，**不受《劳动法》保护** |
| **签订时间** | 在校期间的任何实习 |
| **核心条款** | 实习时间、岗位内容、实习报酬、保密义务、安全责任、保险 |
| **是否有工资** | 双方协商，不强制；职业学校学生有最低标准（同岗位80%） |
| **是否有社保** | ❌ **没有**，实习不属于劳动关系 |
| **是否影响应届生身份** | ❌ **不影响** |
| **能否随时终止** | ✅ 可以，提前通知即可 |
| **能否签多家** | ✅ 可以，同时签多家实习协议 |

**⚠️ 实习协议注意事项**：

1. **必须书面签订**。口头约定无保障。
2. **实习报酬要明确**。写明月薪/日薪、支付日期、支付方式。
3. **工作时间要写清楚**。每天几小时、每周几天、有无加班。
4. **保险要问**。正规企业会为实习生买**人身意外伤害保险**。
5. **保密条款要小心**。有些企业实习协议里有竞业/保密，限制你离职后去竞品。
6. **不要签成劳动合同**。如果协议里有"试用期""社保""公积金"等字眼，要警惕——你可能被企业当成正式员工，但你享受不到劳动法保护。

**标准实习协议模板必备条款**（教育部推荐）：

```
- 实习期限：____年____月____日至____年____月____日
- 实习岗位：________________
- 工作时间：每日____小时，每周____天
- 实习报酬：____元/月（或____元/天），支付周期不超过1个月
- 保险：实习单位应为实习生办理人身意外伤害保险
- 保密义务：实习生对实习期间接触的商业秘密负有保密义务
- 协议解除：双方协商一致可解除，提前____天通知
```

### 2.3 三方协议（就业协议书）

| 维度 | 说明 |
|------|------|
| **法律性质** | 民事合同（意向书），约定"毕业后去某企业工作" |
| **签订时间** | 毕业前（秋招/春招拿到 Offer 后） |
| **签订方** | 学校 + 学生 + 企业（三方缺一不可） |
| **核心条款** | 工作岗位、工作地点、户口档案去向、违约金、报到时间 |
| **是否有工资** | ❌ 不写工资待遇，那是劳动合同的事 |
| **是否有社保** | ❌ **没有**，三方≠劳动关系 |
| **是否影响应届生身份** | ❌ **不影响** |
| **能否签多家** | ❌ 不能。一个学生只能有一份三方（学校系统控制） |
| **能否毁约** | ✅ 可以，但需付违约金；学校一般有毁约次数限制 |

**⚠️ 三方协议注意事项**：

1. **三方≠劳动合同**。签了三方不代表你被正式录用，企业仍可能毁约。
2. **违约金双向约定**。通常写学生违约赔 3,000–5,000 元；企业违约一般无赔偿。
3. **报到时间**。通常写"毕业后报到"，不强制提前实习。
4. **档案去向**。签了三方后，学校按协议上的地址派遣档案。毁约后需办理**改派**。
5. **户口迁移**。如果企业承诺解决户口，三方上应写明。
6. **是否可以不去实习**。✅ **可以**。三方只约定毕业后去工作，不约定提前实习。

**三方协议标准模板必备条款**：

```
- 用人单位：________________（全称）
- 毕业生：________________
- 培养学校：________________
- 工作岗位：________________
- 工作地点：________________
- 户口迁移：□ 迁至单位 □ 迁至人才市场 □ 回生源地
- 档案转递：□ 转至单位 □ 转至人才市场 □ 回生源地
- 报到期限：毕业后____日内
- 违约金：学生违约____元 / 单位违约____元
```

### 2.4 劳动合同（毕业后正式入职时签）

| 维度 | 说明 |
|------|------|
| **法律性质** | 受《劳动合同法》严格约束，双方建立劳动关系 |
| **签订时间** | 毕业后正式入职时（或毕业前以"应届生"身份提前入职） |
| **核心条款** | 工作内容、工作地点、劳动报酬、工作时间、社保公积金、试用期 |
| **是否有工资** | ✅ 必须有，且不得低于当地最低工资标准 |
| **是否有社保** | ✅ **必须有**，五险一金是法定义务 |
| **是否影响应届生身份** | ✅ **影响！缴了社保 = 已就业 = 失去应届生身份** |
| **能否随时终止** | ❌ 有解除条件，需提前 30 天书面通知（试用期 3 天） |
| **能否签多家** | ❌ 不能。一个人只能有一份全日制劳动合同 |

**⚠️ 劳动合同注意事项**：

1. **试用期有上限**。劳动合同 1 年以下，试用期不超过 1 个月；1–3 年，不超过 2 个月；3 年以上，不超过 6 个月。
2. **试用期工资有下限**。不得低于转正工资的 80%，且不得低于当地最低工资标准。
3. **试用期也要缴社保**。《社会保险法》规定，用人单位应当自用工之日起 30 日内为职工办理社保登记。
4. **劳动合同 vs 劳务合同**。有些企业让你签"劳务合同"来规避劳动法——劳务合同不缴社保、不受劳动法保护，**不要签**。
5. **竞业限制协议**。部分企业要求签竞业协议（限制离职后去竞品），通常针对高管/技术人员，普通运维岗一般不需要签。

### 2.5 劳务合同（Freelance / 兼职时签）

| 维度 | 说明 |
|------|------|
| **法律性质** | 民事合同，双方是"合作关系"而非"劳动关系" |
| **是否有社保** | ❌ 不缴社保 |
| **是否影响应届生身份** | ❌ **不影响** |
| **风险** | 不受劳动法保护，发生工伤难维权 |

**与劳动合同的核心区别**：

| 对比项 | 劳动合同 | 劳务合同 |
|--------|----------|----------|
| 关系 | 雇主-雇员 | 甲方-乙方 |
| 管理 | 企业对你有管理权 | 你独立工作，不受企业管理 |
| 社保 | ✅ 必须缴 | ❌ 不缴 |
| 个税 | 按工资薪金扣缴 | 按劳务报酬扣缴 |
| 工伤 | 工伤保险赔付 | 自己承担 |

**⚠️ 陷阱**：有些企业为了省社保成本，让全职员工签劳务合同——这是违法的，你可以拒绝。

### 2.6 保密协议 / 竞业限制协议

| 维度 | 保密协议 | 竞业限制协议 |
|------|----------|-------------|
| **目的** | 保护企业商业秘密 | 限制离职后去竞品 |
| **适用对象** | 几乎所有员工 | 通常限于高管、技术人员、核心人员 |
| **有效期** | 在职期间 + 离职后 2 年内 | 离职后不超过 2 年 |
| **是否有补偿** | 无 | ✅ 离职后每月需支付补偿金（不低于离职前月平均工资的 30%）|

## 三、求职路上各类协议时间线

```
在校期间（2026年8月-2027年5月）
  ├── 找实习
  │   └── 签实习协议 ← 民事合同，不缴社保，不影响应届生身份
  │
  ├── 参加秋招/春招
  │   └── 拿到 Offer → 签三方协议 ← 意向书，不缴社保，不影响应届生身份
  │
  └── 毕业前企业要求提前入职
      └── 签劳动合同 ← ⚠️ 注意！缴社保 = 失去应届生身份
      └── 建议：尽量毕业后再签劳动合同，或确认企业不缴社保

毕业后（2027年6月起）
  ├── 去签了三方的企业报到
  │   └── 签劳动合同 ← 正式入职，缴社保，确立劳动关系
  │
  └── 想换工作
      └── 提前30天通知 → 解除劳动合同 → 找新工作 → 签新劳动合同
```

## 四、三方协议与秋招实操问答

### Q1：签了三方协议 = 实习到毕业直接转正？

**答案：不是。三方协议 ≠ 劳动合同，签了三方不代表自动转正。**

**三方的真实作用**：
- 三方协议是**就业意向书**，不是劳动合同
- 签了三方**不意味着**必须去该企业实习
- 转正条件：毕业前/毕业后需与企业签订**正式劳动合同**

**签三方后的常见路径**：

```
路径 A：签三方 → 毕业前实习（可选）→ 毕业 → 签正式劳动合同 → 转正
路径 B：签三方 → 毕业前不去实习 → 毕业 → 签正式劳动合同 → 入职
路径 C：签三方 → 毕业前找到更好的机会 → 毁约（付违约金）→ 签新三方
路径 D：签三方 → 毕业前企业毁约 → 学生重新找工作
```

**签三方后的注意事项**：

| 事项 | 说明 |
|------|------|
| **违约金** | 三方协议通常约定违约金（常见 3,000–5,000 元），学生毁约需支付 |
| **企业毁约** | 企业毁约一般无需赔偿学生，但需协商解除三方 |
| **档案去向** | 签三方后，学校按三方上的企业地址派遣档案；毁约后需办理改派 |
| **社保问题** | 签三方**不等于缴社保**；实习期间通常不缴社保，不影响应届生身份 |

> 一个常见误区："签了三方就要去这家企业实习到毕业" —— **错误**。三方只约定"毕业后去该企业工作"，是否提前实习需**单独签订实习协议**约定。

### Q2：各种求职失败情况的完整应对方案

**首先，不要慌。秋招/春招不是唯一机会。以下按"最好情况"到"最坏情况"分级应对。**

---

#### 情况一：拿到了 Offer，但想换更好的

| 现状 | 你有保底，心态稳 |
|------|----------------|
| **行动** | 签三方保底，继续投递更好的企业 |
| **注意** | 毁约可能有违约金（3,000-5,000元），学校一般限毁约1次 |
| **时间** | 2026年11月前决定，拖太晚影响档案派遣 |

---

#### 情况二：拿到了 Offer，但实习后发现不合适

| 现状 | 有 Offer，但想跑路 |
|------|-------------------|
| **行动** | ① 拿到新的书面 Offer → ② 与原单位协商解约 → ③ 付违约金 → ④ 学校申请新三方 |
| **注意** | 必须先拿到新 Offer 再毁旧约；口头 Offer 不算数 |
| **红线** | 实习期间只签实习协议，不签劳动合同，不缴社保 |

---

#### 情况三：秋招没拿到 Offer，但找到了实习

| 现状 | 有实习，但没转正 |
|------|----------------|
| **行动** | ① 实习期间全力表现争取转正 → ② 同步准备春招 → ③ 实习到期不转正则春招保底 |
| **注意** | 实习协议到期前1个月问 leader"转正可能性"；不给明确答复就启动春招 |
| **红线** | 实习不缴社保；如果企业说"转正必须签劳动合同缴社保"，问清楚是"实习转正"还是"毕业入职" |

---

#### 情况四：秋招没拿到 Offer，也没找到实习

| 现状 | 两手空空，最焦虑 |
|------|----------------|
| **行动** | ① 复盘秋招失败原因 → ② 11-12月秋招补录 → ③ 12月起找日常实习 → ④ 2027年2-5月春招 |
| **关键** | "没实习"不代表"没机会"；日常实习全年都有，不卡秋招春招时间 |
| **心态** | 很多学长学姐是"日常实习转正"拿到的 Offer，不是秋招 |

---

#### 情况五：春招也没拿到 Offer，毕业了还没着落

| 现状 | 毕业即失业 |
|------|-----------|
| **行动** | ① 就业见习基地（3-6个月，有补贴，期满转正）→ ② 社招初级岗 → ③ 考公/考编 |
| **见习** | 南京/常州有见习基地；补贴约 1,500-2,000/月；**不算就业，保留应届生身份** |
| **社招** | 搜"运维助理""技术支持（应届）""初级工程师"；强调实习+项目 |
| **考公** | 2027年11月国考 / 2028年3月省考；应届生身份保留2年 |

---

#### 情况六：连实习都找不到

| 现状 | 简历投出去没回音，面试都没有 |
|------|---------------------------|
| **先问自己三个问题** | ① 简历是不是一份投所有？② 是不是只投了10家就放弃了？③ 技能是不是真的匹配岗位？ |
| **立即行动** | ① 重写简历（突出项目+关键词）→ ② 降低目标（先投小公司练手）→ ③ 做个人项目补经历 → ④ 找校友内推 |
| **个人项目建议** | 用 Python + MQTT 搭一个"智能家居监控系统"，部署到阿里云/腾讯云，写博客/做视频 |
| **心态** | 找不到实习 ≠ 你不行；可能是目标定太高、简历没写好、或者投得不够多 |

---

#### 情况七：实习了但没转正，毕业后怎么办？

| 路径 | 说明 | 适合谁 |
|------|------|--------|
| **路径 A：就业见习基地** | 政府组织，3-6个月，有补贴，期满可转正 | 最推荐，保留应届生身份 |
| **路径 B：继续找日常实习** | 毕业后也可以实习，签实习协议，不缴社保 | 目标是"实习表现好→转正" |
| **路径 C：社招初级岗** | 投"运维助理""初级工程师"等 | 接受与有经验者竞争 |
| **路径 D：考公/考编** | 应届生身份保留2年 | 想进体制内 |
| **路径 E：考研** | 保留应届生身份备考 | 想提升学历 |

**不能参加 2028 届校招**：2028 届校招只招 2028 年 6 月毕业的学生，你是 2027 届，**无法参加**。
**但可以参加**：接受往届生的校招（如宝洁、部分国企）、社招、考公、见习。

| 红线 | 为什么重要 | 违反后果 |
|------|-----------|----------|
| **实习期间不缴社保** | 缴社保 = 失去应届生身份 | 考公/考编/部分校招资格作废 |
| **只签实习协议，不签劳动合同** | 劳动合同 = 缴社保 = 同上 | 同上 |

**降低秋招失败概率的方法（现在就能做）**：

1. **简历不要一份投所有**：针对每家企业微调关键词
2. **海投策略**：秋招期间目标投递 **100+** 家企业，不是 10 家
3. **内推**：找校友、学长学姐内推，简历直达面试官
4. **提前批**：7-8 月就投提前批，避开 9-10 月的高峰期
5. **保底策略**：先拿一个保底的 Offer，再冲高目标
6. **先做个人项目**：没有实习经历，就用项目补（GitHub + 博客）

### Q3：秋招有人要，但学校有课怎么办？

**这种情况非常常见，有成熟的处理方式。**

**场景分析**：


**场景分析**：

| 场景 | 处理方案 |
|------|----------|
| **企业要求立即全职实习，但学校还有课** | 与企业协商**延后入职**或改为**每周 2-3 天兼职实习** |
| **企业要求必须去外地实习** | 协商远程实习；或向学校申请**顶岗实习学分替代** |
| **学校不允许大四上学期外出实习** | 签三方但**不提前实习**，毕业后再入职 |
| **企业要求实习到毕业才给转正** | 签实习协议（非劳动合同），明确实习报酬和转正条件 |

**关键原则**：

| 原则 | 说明 |
|------|------|
| **学业优先** | 挂科会影响毕业，没有毕业证 = Offer 作废 |
| **三方 ≠ 必须实习** | 签了三方不代表必须现在就去实习 |
| **协商空间很大** | 企业对校招生通常有包容度，愿意配合学校时间 |
| **可以远程实习** | 运维/DevOps 岗位很多支持远程/弹性工作 |

**与企业协商的标准话术**：

> "您好，我是 2027 届毕业生，目前学校还有必修课（或毕业设计），需要到 2027 年 6 月才能全职到岗。请问贵公司是否接受：① 先签三方，毕业后正式入职；② 或者先以每周 2-3 天的方式远程实习？"

### Q4：签了三方还能继续找别的实习吗？

**可以。** 你完全可以签了三方后，继续在其他公司实习（只要那家实习公司不为你缴纳社保）。三方只约束"毕业后去该企业工作"，不约束你毕业前的实习选择。

### 秋招关键决策表

| 情境 | 你的选择 | 注意事项 |
|------|----------|----------|
| 拿到 Offer，学校有课 | 签三方，协商延后入职或远程实习 | 不要翘课全职实习 |
| 拿到 Offer，想继续看更好的 | 签三方保底，继续投其他企业 | 毁约可能有违约金 |
| 没拿到 Offer，很焦虑 | 复盘→补录→日常实习→春招 | 秋招不是唯一机会 |
| 拿到 Offer，但不想去了 | 协商毁约（付违约金）→重新签三方 | 学校可能限制毁约次数 |
| 企业在秋招时要求实习才给 Offer | 问清楚是否签三方、实习协议还是劳动合同 | 签劳动合同 = 缴社保 = 失去应届生身份 |

## 五、实习权益与法律保障

### 5.1 核心法律框架

实习期间的权益主要受以下法规约束：

| 法规 | 适用范围 | 核心内容 |
|------|----------|----------|
| **《职业学校学生实习管理规定》**（教育部等八部门，2022 年修订） | 职业学校学生 | 实习协议、报酬、保险、工时、安全 |
| **《劳动合同法》** | 构成劳动关系的实习生 | 最低工资标准、社保、工时 |
| **《关于贯彻执行〈劳动法〉若干问题的意见》**（劳部发〔1995〕309 号） | 在校生勤工助学 | 在校生勤工助学不视为就业，未建立劳动关系 |

**关键区分**：
- **教学实习/社会实践**：不构成劳动关系 → 不适用劳动法 → 报酬由双方协商
- **就业型实习（以留用为目的）**：可能被认定为事实劳动关系 → 适用劳动法 → 不得低于最低工资标准

### 5.2 实习报酬的法律规定

#### （1）职业学校学生（教育部规定）

**政策原文**：

> 《职业学校学生实习管理规定》第十七条：
> "接收学生岗位实习的实习单位，应当参考本单位相同岗位的报酬标准和岗位实习学生的工作量、工作强度、工作时间等因素，给予适当的实习报酬。在实习岗位相对独立参与实际工作、初步具备实践岗位独立工作能力的学生，实习报酬原则上应不低于本单位相同岗位工资标准的 **80%** 或最低档工资标准，并按照实习协议约定，以货币形式及时、足额、直接支付给学生，支付周期原则上不得超过 **1 个月**，不得以物品或代金券等代替货币支付或经过第三方转发。"

**要点**：
- 报酬标准：不低于同岗位工资 80% 或最低档工资
- 支付形式：货币，不得用实物/代金券代替
- 支付周期：不超过 1 个月
- 支付对象：直接支付给学生本人

#### （2）普通在校实习生（非职业学校）

**政策原文**：

> 劳部发〔1995〕309 号第 12 条："在校生利用业余时间勤工助学，不视为就业，未建立劳动关系，可以不签订劳动合同。"

**结论**：
- 普通在校生实习**不构成劳动关系**
- 实习报酬**无法律强制最低标准**，由双方协商
- 但如果实习以就业留用为目的、用人单位实施劳动管理，可能被认定为**事实劳动关系**

#### （3）见习人员（毕业后）

**政策原文**：

> "见习单位应当每月向见习人员提供不低于当地最低工资标准 **80%** 的生活补贴。"

### 5.3 实习期间的保险

| 保险类型 | 法律要求 | 说明 |
|----------|----------|------|
| **工伤保险** | ⚠️ 部分地区要求 | 部分地区规定实习单位应为实习生办理特定人员单险种工伤保险 |
| **人身意外伤害保险** | ✅ 强烈建议 | 教育部规定实习单位应为实习生购买人身意外伤害保险 |
| **社会保险（五险一金）** | ❌ 实习期通常不缴 | 因不构成劳动关系，一般不缴纳社保 |

**政策原文**：

> 《职业学校学生实习管理规定》："实习协议应明确责任保险与伤亡事故处理办法。""实习单位应为实习学生办理意外伤害保险。"

### 5.4 实习期间的工作时间与休息

**政策原文**：

> 《职业学校学生实习管理规定》第十六条：
> "除相关专业和实习岗位有特殊要求，并报上级主管部门备案的除外，实习单位应遵守国家关于工作时间和休息休假的规定，不得安排学生在休息日、法定节假日实习，不得安排学生加班和上夜班。"

**要点**：
- 一般不得安排周末/节假日实习
- 不得安排加班和夜班
- 每日工作时间不超过 8 小时

### 5.5 实习期间的禁止行为

**政策原文**：

> 《职业学校学生实习管理规定》第十五条，职业学校和实习单位不得有下列情形：
> 1. 安排一年级在校学生顶岗实习；
> 2. 安排未满 16 周岁的学生跟岗/顶岗实习；
> 3. 安排未成年学生从事禁忌劳动；
> 4. 安排女学生从事女职工禁忌劳动；
> 5. 安排学生到酒吧、夜总会、歌厅、洗浴中心、电子游戏厅、网吧等营业性娱乐场所实习；
> 6. 通过中介机构或有偿代理组织、安排和管理学生实习工作；
> 7. 安排学生从事 III 级强度及以上体力劳动或其他有害身心健康的实习。

### 5.6 实习协议必备条款

**政策原文**：

> 《职业学校学生实习管理规定》第十三条，实习协议应包括但不限于以下内容：
> 1. 各方基本信息；
> 2. 实习的时间、地点、内容、要求与条件保障；
> 3. 实习期间的食宿、工作时间、休息休假安排；
> 4. 实习报酬及支付方式；
> 5. 劳动保护、安全卫生、职业病危害防护条件；
> 6. 责任保险与伤亡事故处理办法；
> 7. 实习考核方式；
> 8. 各方违约责任；
> 9. 其他事项。

### 5.7 你的实习权益清单

作为 2027 届本科毕业生，实习期间应注意：

| 权益 | 法律依据 | 你的行动 |
|------|----------|----------|
| **签订书面实习协议** | 教育部规定 | ✅ 必须要求签订，明确报酬、工时、保险 |
| **获得实习报酬** | 双方协商 / 教育部规定（职业学校） | ✅ 明确金额、支付方式、支付周期 |
| **工作时间不超过 8 小时/天** | 教育部规定 | ✅ 拒绝超时加班 |
| **休息日不安排实习** | 教育部规定 | ✅ 法定节假日有权休息 |
| **人身意外伤害保险** | 教育部规定 | ✅ 要求单位购买，或自行购买 |
| **不被收取任何费用** | 教育部规定 | ✅ 单位不得收取押金、培训费、管理费 |
| **不被扣押证件** | 教育部规定 | ✅ 单位不得扣押身份证、学生证 |

## 六、档案与户口

### 6.1 档案去哪

| 情况 | 档案去向 | 操作 |
|------|----------|------|
| 签了三方（有明确单位） | 转至单位或单位委托的人才市场 | 三方上填写档案接收地址 |
| 未签三方 / 继续求职 | 转回生源地人才市场 或 学校暂存2年 | 向学校申请"档案留校"或"回原籍" |
| 专升本学生 | 专科档案 + 本科档案合并 | 确认学校是否已合并，避免档案断档 |

**关键提醒**：
- 档案**不能自己拿着**，必须通过学校走机要通道寄送
- 档案断档（丢失/在自己手里超过2年）会影响考公、落户、职称评定
- 毕业后在"全国人社政务服务平台"查询档案去向

### 6.2 户口迁移

| 情况 | 处理方式 |
|------|----------|
| 户口在学校集体户 | 毕业时迁回原籍 或 迁至工作地（企业可落户）|
| 户口在原籍 | 一般不用动；企业可落户时再迁 |
| 去上海/北京工作 | 本科一般不能直接落户，需走积分/人才引进 |
| 去苏州/南京工作 | 本科一般可直接落户，走"先落户后就业" |

**提醒**：户口迁移证有效期通常40天，不要超期。

## 八、网申填写的机器筛选技巧

### 8.1 HR 系统怎么筛简历

大部分企业用 ATS（Applicant Tracking System）自动筛选：

| 筛选维度 | 你的对策 |
|----------|----------|
| **学历关键词** | 写"本科"而不是"专升本"；系统只扫"本科"两个字 |
| **技能关键词** | 把JD里的技能词原样复制进简历（Linux、Docker、MQTT、Python）|
| **毕业时间** | 统一写"2027年6月"，不要写"预计" |
| **实习时长** | 不满3个月写"短期项目"，满3个月写"实习" |
| **英文水平** | 不写"正在学"，写"能阅读英文技术文档" |

### 8.2 网申系统常见坑

| 坑 | 对策 |
|----|------|
| 每个企业独立系统，信息重复填 | 提前准备一份"标准信息文档"（教育经历、项目经历、证书编号）直接复制粘贴 |
| 上传简历后系统解析错误 | 用标准模板（不要花哨排版），文件名写"姓名_岗位_院校_2027届" |
| 开放性问题（OQ）| 提前准备3个故事：①最有成就感的项目 ②解决过的最大困难 ③团队协作案例 |

## 九、内推的价值和获取方式

### 9.1 内推 vs 海投

## 十、薪资谈判

### 10.1 校招是否可谈薪

| 企业类型 | 可谈薪程度 |
|----------|-----------|
| 大厂（阿里/腾讯等） | 基本不可谈，有统一薪资标准（白菜价/SP/SSP） |
| 中厂 | 小幅可谈（±10-20%），看面试评级 |
| 国企/央企 | 基本不可谈，按职级定薪 |
| 创业公司/小厂 | 可谈空间较大 |
| 外企 | 可谈，但幅度有限 |

### 10.2 你的预期薪资参考

| 岗位 | 城市 | 实习期 | 转正后（本科） |
|------|------|--------|---------------|
| 运维实习生 | 苏州/无锡 | 3k-5k | 6k-10k |

**谈判策略**：

## 十三、背景调查（背调）

### 13.1 什么企业会做背调

| 企业类型 | 背调深度 |
|----------|----------|
| 大厂/外企 | 严格，查学历、工作经历、犯罪记录 |
| 国企/央企 | 中等，重点查学历和政治面貌 |
| 中小公司 | 很少做，或只打个电话问问 |

### 13.2 背调查什么

| 维度 | 查什么 | 你的风险 |
|------|--------|----------|
| 学历 | 学信网验证 | 无风险，真实学历 |
| 工作经历 | 打前公司HR电话 | 简历不要夸大职位/时长 |
| 犯罪记录 | 公安系统 | 无风险 |
| 法院诉讼 | 裁判文书网 | 无风险 |
| 社交媒体 | 部分外企会查 | 注意公开内容的专业性 |

**提醒**：简历上的经历必须真实，不要虚构公司/项目/职位。背调发现造假 = offer取消。

## 十四、入职第一天

### 14.1 带什么

| 物品 | 说明 |
|------|------|

### 14.2 入职当天流程

1. 到HR处报到 → 签劳动合同 → 领工牌/电脑
2. 见直属leader → 了解团队 → 加工作群
3. 配置开发环境 → 看文档 → 领第一个小任务
4. 不要急着表现，先观察团队节奏和沟通风格

## 十五、实习期怎么转正

### 15.1 企业评估实习生的维度

| 维度 | 权重 | 你的行动 |
|------|------|----------|
| **技术能力** | 30% | 任务完成质量、代码/文档规范 |
| **主动性** | 25% | 主动问问题、主动承担任务 |
| **沟通协作** | 20% | 与团队配合、及时同步进度 |
| **学习能力** | 15% | 遇到新技术能快速上手 |
| **稳定性** | 10% | 是否表现出长期留下的意愿 |

### 15.2 实习期生存法则

| 原则 | 具体操作 |
|------|----------|
| **前两周多问少做** | 问清楚需求、验收标准、相关文档位置 |
| **每天写日报** | 即使公司不要求，主动发邮件/消息同步进展 |
| **遇到阻塞立即说** | 不要憋2天做不出来才问，卡住1小时就问 |
| **记录踩过的坑** | 形成自己的知识库，也是转正答辩的素材 |
| **观察正式员工** | 他们怎么写邮件、怎么开例会、怎么提问题 |
| **不要踩点下班** | 至少比leader晚走10-15分钟（除非leader走得很早）|

### 15.3 转正答辩准备

通常实习2-3个月后会有一次转正答辩：

```
转正答辩结构（5-10分钟）
  ├── 自我介绍（1分钟）
  ├── 实习期间完成的工作（3-5分钟）
  │   ├── 项目1：背景+你的角色+技术方案+成果
  │   └── 项目2：...
  ├── 遇到的问题及解决（2分钟）
  ├── 收获与成长（1分钟）
  └── 未来规划（1分钟）
```

## 十六、接 offer 后拿到更好的怎么办

### 16.1 毁约流程

| 步骤 | 操作 |
|------|------|
| 1. 确认新offer | 收到书面offer（邮件/纸质），不要只凭口头 |
| 2. 与原单位协商 | 说明情况，请求解除三方；态度诚恳，不要拖延 |
| 3. 支付违约金 | 按三方约定支付（通常3,000-5,000元） |
| 4. 学校办理解约 | 拿原单位解约函 → 到学校就业中心申请新三方 |
| 5. 签新三方 | 与新单位签新的三方协议 |

### 16.2 学校对毁约的态度

| 学校政策 | 说明 |
|----------|------|
| 一般允许毁约1次 | 部分学校限制毁约次数（如最多1次） |
| 需要原单位解约函 | 没有解约函学校不给新三方 |
| 毁约时间 | 尽量在毕业前3个月办妥，避免影响档案派遣 |

**提醒**：
- 不要同时签两家三方，这是诚信问题
- 毁约要尽早，不要拖到毕业前才说
- 有些企业（尤其是国企）毁约后可能影响后续合作

## 十八、劳动法基础知识

### 18.1 试用期权利

| 权利 | 说明 |
|------|------|
| 试用期工资 | ≥转正工资的80%，且≥当地最低工资 |
| 试用期时长 | 1年合同≤2个月；3年合同≤6个月 |
| 试用期社保 | 必须缴纳，入职30日内办理 |
| 试用期辞职 | 提前3天通知即可 |
| 试用期被辞退 | 企业需证明"不符合录用条件"，否则违法 |

### 18.2 常见违法情形

| 违法情形 | 你的对策 |
|----------|----------|
| 试用期不缴社保 | 保留证据，向劳动监察大队投诉 |
| 试用期工资低于80% | 协商补发，或申请劳动仲裁 |
| 强制加班无加班费 | 保留考勤记录，离职时一起算 |
| 试用期随意辞退 | 要求企业出具书面辞退理由 |

## 二十、常见陷阱与应对

### 陷阱 1：签了三方就必须去实习

**真相**：三方只写毕业后报到，不写提前实习。企业不能强迫你提前实习。

**应对**：
> "我已经签了三方，但学校还有课程/毕业设计，无法提前全职实习。我保证毕业后按时报到，请问是否可以？"

### 陷阱 2：实习协议里有"试用期"

**真相**：试用期是劳动合同的概念，实习协议里写"试用期"可能是企业想规避劳动法。

**应对**：要求删除"试用期"字样，明确这是实习不是入职。

### 陷阱 3：签劳务合同代替劳动合同

**真相**：企业为了省社保成本，让全职员工签劳务合同。

**应对**：
> "我了解劳务合同和劳动合同的区别。我的工作内容和时间符合劳动关系特征，请按法律规定签订劳动合同。"

### 陷阱 4：三方协议违约金过高

**真相**：违约金一般不超过 5,000 元，过高的条款可能被认定为无效。

**应对**：与企业协商降低违约金；如协商不成，可考虑不签这家。

### 陷阱 5：口头承诺不写进协议

**真相**：口头承诺没有法律效力。

**应对**：所有承诺（薪资、岗位、户口、住宿）都要求写进三方或劳动合同。

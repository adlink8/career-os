## 一、AI 认定企业是什么？包括哪些？

**苏州 AI 人才专项补贴**中提到的"经认定的苏州市人工智能企业和新型研发机构"，是指由苏州市相关主管部门（发改委人工智能推进处、工信局、科技局等）按照一定标准认定并公布名单的企业和机构。

- **不是**只有"造 AI 的"（如大模型公司）才算 AI 企业

## 二、秋招春招关键时间线与具体操作

### 2.1 校招时间轴总览（以 2027 届为例）

```
2026年
├── 6-7月   暑期实习提前批（部分大厂提前锁定人才）
├── 7-8月   秋招提前批（互联网/科技公司为主）
├── 8-10月  秋招正式批（主战场！岗位最多）
├── 10-11月 秋招补录/面试高峰
├── 11-12月 秋招收尾，部分 Offer 发放
├── 12-1月  寒假复盘期
│
2027年
├── 2-3月   春招启动（补录为主）
├── 3-5月   春招高峰期
├── 5-6月   春招收尾
├── 6月     毕业
└── 7-8月   入职 / 部分企业秋招提前批启动（针对 2028 届）
```

### 2.2 各阶段详解

#### 阶段一：暑期实习（2026 年 6-8 月）

| 项目 | 说明 |
|------|------|
| **目标** | 争取转正机会，提前拿到正式 Offer |
| **对象** | 2027 届毕业生 |
| **关键行动** | 5-6 月投暑期实习简历；6-8 月实习；8-9 月答辩转正 |
| **转正率** | 大厂暑期实习转正率通常 50-70% |

> 你的情况：目前已进入 2026 年 8 月，暑期实习窗口基本关闭。但如果能找到日常实习（非暑期），表现好也可能获得转正推荐。

#### 阶段二：秋招提前批（2026 年 7-8 月）

| 项目 | 说明 |
|------|------|
| **特点** | 流程简化、竞争较小、岗位核心 |
| **适用企业** | 互联网大厂（腾讯、阿里、字节、百度等）|
| **关键行动** | 7 月起关注各公司招聘公众号/官网；提前准备技术面试 |

| 项目 | 说明 |
|------|------|

| **时间节奏** | 8 月启动 → 9-10 月笔试面试高峰 → 10-11 月 Offer 发放 |
| **覆盖行业** | 互联网、国企、银行、外企、制造业、新能源 |
| **你的策略** | 重点投递 IoT/运维/技术支持/DevOps 岗位 |

| 行业 | 启动时间 | 高峰期 | 特点 |

| 国企/央企 | 9-10 月 | 10-11 月 | 流程长、稳定、有编制 |

### 2.3 具体操作流程（以互联网/科技企业为例）

```
Step 1: 网申（8-9月）
  ├── 准备材料：简历（中文+英文）、成绩单、证书扫描件
  ├── 投递渠道：企业官网/招聘公众号/BOSS直聘/实习僧
  └── 注意：每个企业独立系统，信息需重复填写

Step 2: 在线测评（网申后1-2周）
  ├── 内容：性格测试、逻辑推理、数学计算、英语阅读
  └── 注意：部分企业测评有摄像头监控

Step 3: 笔试（测评通过后1-2周）
  ├── 技术岗：编程题（LeetCode风格）、系统设计、计算机网络/操作系统
  ├── 非技术岗：行测、申论、案例分析
  └── 注意：秋招提前批可能免笔试

Step 4: 面试（笔试通过后1-2周）
  ├── 一面：技术面试（基础知识+项目深挖）
  ├── 二面：技术面/主管面（系统设计+场景题）
  ├── 三面：HR面（职业规划+薪资期望+企业文化匹配）
  └── 注意：每轮间隔 3-7 天；部分企业有交叉面

Step 5: Offer发放
  ├── 时间：面试通过后 1-4 周
  ├── 形式：邮件/电话 Offer
  └── 注意：大部分 Offer 有有效期（通常7-14天），需及时确认

Step 6: 签约/三方协议
  ├── 学校发放三方协议
  ├── 企业盖章 → 学生签字 → 学校盖章
  └── 注意：毁约可能有违约金（通常 3,000-5,000 元）
```

## 三、毕业后是否只能走社招？应届生身份详解

### 3.1 核心结论：毕业后不是只能走社招！

**应届生身份有两层含义**：

| 层面 | 定义 | 适用场景 |
|------|------|----------|
| **当年应届生** | 当年毕业的在校生/刚毕业 | 企业校招（主流）|
| **择业期应届生** | 毕业后 2 年内未就业、未缴社保 | 公务员考试、部分国企/外企 |

**关键区分**：
- **公务员考试**：毕业后 2 年内未就业，均可按应届生报考 ✅
- **企业校招**：大部分企业只认"当年应届生"（毕业时间当年）❌
- **部分国企/外企**：接受毕业 2 年内的往届生（如宝洁、联合利华）✅

### 3.2 国家政策：择业期制度

**政策原文**：

> 国家统一招生的普通高校毕业生离校时和在择业期内（国家规定择业期为 **2 年**，部分地区延长至 **3 年**）未落实工作单位，其户口、档案、组织关系保留在原毕业学校，或保留在各级毕业生就业主管部门、各级人才交流服务机构和各级公共就业服务机构的毕业生，可按应届高校毕业生对待。

**保留应届生身份的四个条件**：

1. ✅ 未签订三方协议
2. ✅ 未签订劳动合同
3. ✅ **未缴纳社保**（最关键！）
4. ✅ 档案在学校或人才市场

**⚠️ 一旦缴纳社保，即视为"已落实工作单位"，失去应届生身份！**

### 3.3 北京最新政策：放宽应届生认定

**政策原文**（2025 年 11 月）：

> "本市机关事业单位、地方国有企业招录（聘）'应届高校毕业生'的岗位，应向毕业证书落款年度 **2 年内**（含毕业当年度）的高校毕业生开放，**不对其是否有工作经历、缴纳社保作限制**。"

**关键突破**：
- 北京机关事业单位和国企招录应届生岗位时，**不查社保、不查工作经历**
- 毕业证书落款年度 2 年内均可报考
- 这与国家公务员考试政策保持一致

**但注意**：
- 此政策仅适用于**机关事业单位和国企**
- **民营企业校招**仍按企业自己的标准（通常只认当年毕业）

### 3.4 毕业后可以参加的招聘类型

| 招聘类型 | 毕业后是否能参加 | 条件 | 典型企业 |
|----------|-----------------|------|----------|
| **当年校招（秋招/春招）** | ⚠️ 部分可以 | 企业是否接受往届生 | 快消（宝洁/联合利华）、部分国企 |
| **公务员考试（国考/省考）** | ✅ 可以 | 择业期内未就业 | 各级政府机关 |
| **事业单位招聘** | ✅ 可以 | 择业期内 | 公立学校、医院等 |
| **国企校招** | ✅ 部分可以 | 部分国企接受毕业 2 年内 | 国家电网、三大运营商 |
| **外企校招** | ✅ 部分可以 | 工作经验小于 2 年 | 宝洁、联合利华、四大 |
| **社会招聘（社招）** | ✅ 可以 | 无限制 | 所有企业 |

### 3.5 校招 vs 社招对比

| 维度 | 校招 | 社招 |
|------|------|------|
| **门槛** | 学历导向，经验要求低 | 经验导向，要求能独立上手 |
| **竞争** | 与同届学生竞争 | 与全行业有经验者竞争 |
| **培养** | 有系统化培训、导师制 | 通常直接上岗，培训较少 |
| **薪资** | 有统一校招薪资标准 | 按经验议价，浮动大 |
| **岗位数量** | 集中释放，信息透明 | 分散发布，需主动搜索 |
| **你的优势** | 学历满足、项目经验可包装 | 实习经验不足，竞争力弱 |

**结论**：对于 2027 届的你，**秋招是最佳机会**，应尽量在毕业前通过校招拿到 Offer。

### 3.6 如果秋招/春招都没拿到 Offer 怎么办？

| 路径 | 策略 |
|------|------|
| **走社招** | 以"应届生"身份投社招中的"初级/助理"岗位；强调实习经历和项目经验 |
| **就业见习** | 参加政府组织的就业见习（如南京/常州见习基地），见习期享受生活补贴，期满可转正 |
| **继续实习** | 找一份能转正的实习，毕业前/毕业后先实习再转正 |
| **考研/考公** | 保留应届生身份备考 |
| **灵活就业** | 自由职业/远程工作积累项目经验 |

### 3.7 应届生身份保护清单

在毕业前和毕业后，如果你希望保留应届生身份（用于考公/考编/部分校招），务必做到：

| 事项 | 建议 |
|------|------|
| **实习期间不缴社保** | 签订实习协议而非劳动合同；确认公司不为你缴纳社保 |
| **不签劳动合同** | 实习只签实习协议，不签正式劳动合同 |
| **档案保留在学校或人才市场** | 毕业时申请档案留校或转至生源地人才市场 |
| **不签三方协议（如非必要）** | 三方协议一旦签订，原则上视为已就业 |
| **择业期内不缴社保** | 毕业后 2 年内如未找到理想工作，不要为保留社保记录而随便入职缴社保 |

| 策略 | 说明 |
|------|------|
| **优先投"用 AI"的制造业企业** | 华兴源创、博众精工、科沃斯等；你的 IoT/运维背景与这些企业的 AI 基础设施运维岗高度匹配 |
| **查询认定名单后再投递** | 通过"苏周到"APP 查询苏州 AI 认定企业名单，优先投名单内企业 |
| **不要只盯着"纯 AI"公司** | 纯 AI 公司（如大模型公司）算法岗门槛极高；但 AI 应用企业的运维/技术支持岗门槛适合你 |
| **关注"新型研发机构"** | 苏州实验室、高校研究院等也有 AI 相关岗位，且可能有编制/稳定待遇 |

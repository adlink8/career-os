# 阅读试卷工具 v11 体检与优化清单

> 对象：`C:\Users\li\Desktop\阅读试卷-外刊试跑-20261102-v11.html`（128 KB，单文件，30 题）
> 方法：读源码（`checkAnswers` / `saveAll` / `getAns` / 事件绑定 / CSS）+ 逐项验证
> 结论：**内容层已经很强（逐句翻译、选项解析、标记批注、手写层），短板集中在"做题过程管理"和"数据模型"**。

## 一、现状（实测）

| 能力 | 状态 | 证据 |
| :--- | :--- | :--- |
| 30 题：Q1-20 下拉（选词/匹配）、Q21-30 单选（仔细） | ✅ | `getAns()` 按 n<=20 分支 |
| 对答案 + 总分 | ✅ | `checkAnswers()` 只算 `right/30` |
| 逐题「看解析」 | ✅ | 每 5 题一组静态解析 |
| 逐句双语（`[成分：中文]`） | ✅ | 页面正文 |
| 标记（5 色）+ 红线 + 批注 + 手写 | ✅ | `applyPenLine` / `applyMark` / `addNote` / 画笔 |
| 保存 / 做题日志导出 | ⚠️ | `saveAll()` 存整页 `innerHTML`；日志只在点"对答案"后产生 |
| 主题切换 | ✅ | `cet4-theme` |

## 二、P0（直接影响刷题效率，建议先做）

| # | 问题 | 证据 | 建议 |
| :-: | :--- | :--- | :--- |
| 1 | **没有计时器**，标题写"40 分钟"但页面无倒计时/用时 | 全文件无 `setInterval` / 无计时变量 | 顶部 40:00 倒计时 + 分节建议用时（选词 8' / 匹配 10' / 仔细 22'）；交卷记录总用时 |
| 2 | **对答案不标对错**：选项不变色，只给一个总分 | `checkAnswers()` 只加 `show` 类，未改选项样式 | 正确项绿底、错选红底、未答灰底；每题旁显示 ✓/✗ |
| 3 | **无答题卡总览**，30 题散在长页里 | 无 30 格网格 | 右侧固定 30 格（已答/未答/对/错），点击跳题 |
| 4 | **无键盘操作**：只能点鼠标/滚动 | 事件只有 mouse/touch/resize | A-D / 1-4 选项，↑↓ 切题，Enter 下一题，空格标记 |
| 5 | **数据写死在 HTML**，无法批量生成新卷 | `ANSWERS`、题目、解析全是内联 HTML | 拆成 `paper.json` + 模板：这是"每日自动出卷"的前置条件 |

## 三、P1（体验与可靠性）

| # | 问题 | 证据 | 建议 |
| :-: | :--- | :--- | :--- |
| 6 | 保存用 `innerHTML` 整页快照，改版即失效、易超 localStorage 配额 | `saveAll()` | 存结构化 `{answers, marks, notes, strokes}`，渲染时回填 |
| 7 | `KEY` 带版本号（`...-v11`），换新卷历史清零 | `const KEY='cet4-reading-foreign-1102-v11'` | 历史记录与卷子版本解耦，按日期存多份 |
| 8 | 无自动保存，关页即丢 | 只有手动"保存"按钮 | 每题作答/标记后 800ms 防抖自动存 |
| 9 | 错题只留在日志 txt 里，不能回练 | `downloadLog()` 纯文本 | 导出错题 JSON + 一键生成"错题卷"；可接 Anki |
| 10 | 不能打印 | 无 `@media print` | 加打印样式（隐藏工具栏/解析，保留题目） |
| 11 | 选词/匹配用下拉框，选 15 个词很慢 | `select` | 改成字母按钮组或键盘输入字母；选词空格高亮定位 |
| 12 | 移动端工具栏遮挡正文 | 900px 媒体查询只调宽度 | 工具栏折叠为悬浮按钮；手写层默认关闭 |

## 五、和每日管线的关系

v11 的**内容格式**（逐句双语 + [成分] 标签 + 逐题解析）是资产，要原样保留；
但**承载方式**必须改成 `paper.json → HTML 模板`，否则每天自动出卷只能靠人肉复制 HTML，不可持续。

建议顺序：
1. 先拆数据模型（P0-5）→ 2. 加计时+对错+答题卡（P0-1/2/3）→ 3. 键盘与自动保存（P0-4/P1-8）→ 4. 错题本/打印（P1-9/10）。

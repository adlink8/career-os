## 二、北京市 — 就业/人才/实习政策

### 2.1 整体政策框架

北京市 2025 年发布《关于进一步支持高校毕业生等青年就业创业的通知》，核心要点：

| 政策维度 | 内容 |
|----------|------|
| **应届身份保护** | 毕业证书落款年度 2 年内（含毕业当年度）的高校毕业生，**不限制工作经历、社保缴纳**，均可按应届生报考机关事业单位、国企 |
| **职业技能培训补贴** | 自主参加技能培训，按规定落实职业培训补贴 |
| **青年就业驿站** | 各区建立青年就业驿站，为外地来京求职青年提供**临时住宿、政策对接**等服务 |
| **就业见习岗位** | 全年募集见习岗位不少于 1 万个；全年归集实习岗位不少于 1 万个 |
| **"1131"服务** | 对离校未就业毕业生提供：1 次政策宣介 + 1 次职业指导 + 3 次岗位推荐 + 1 次培训或见习机会 |

**政策原文出处**：北京市人社局等五部门《关于进一步支持高校毕业生等青年就业创业的通知》（2025 年）

### 2.2 各区人才安居政策（不统一，各区自行制定）

⚠️ **北京市没有全市统一的应届毕业生租房/生活补贴政策**，但部分区县和开发区有个人才安居政策：

| 区域 | 政策内容 | 适用对象 |
|------|----------|----------|
| **朝阳区** | 人才公寓 / 租房补贴 | 区内重点企业引进的人才 |
| **海淀区** | 人才租赁住房 / 购房支持 | 高新技术企业人才 |
| **昌平区** | 人才公寓 / 安居补贴 | 区内就业的高层次人才 |
| **顺义区** | 住宿保障 / 安居补贴 | 区内就业的青年人 |
| **经开区（亦庄）** | 人才保租房（市场租金 70%）| 入区企业的在职员工 |
| **门头沟区** | 求职实习免费住 / 入职租金补贴 | 2026 年新推"人才安居七条" |

**关键结论**：
- 北京对普通应届本科毕业生**没有普惠性的一次性求职补贴或租房补贴**
- 人才住房政策以**"以区为主"**方式实施，需入职特定区域/企业后才能享受
- 经开区（亦庄新城）人才保租房按市场租金 **70%** 收取，是目前较具体的福利

### 2.3 职业技能培训补贴 ✅

| 项目 | 内容 |
|------|------|
| **补贴金额** | 按培训项目和等级确定，**最高可达数千元** |
| **适用对象** | 在京就业或求职的高校毕业生等青年 |
| **申请条件** | 自主参加政府补贴性职业技能培训并合格 |
| **申请渠道** | 北京市人社局公布的定点培训机构 |

### 2.4 实习与见习政策

| 类型 | 内容 |
|------|------|
| **实习岗位** | 全年归集不少于 1 万个实习岗位；搭建京津冀大学生实习实践平台 |
| **就业见习** | 全年募集不少于 1 万个见习岗位；见习期享受生活补贴 |
| **见习补贴标准** | 按北京市最低工资标准（2,420 元/月）的一定比例发放 |

### 2.5 你的情况分析

| 维度 | 评估 |
|------|------|
| **一次性求职补贴** | ❌ 北京无普惠性应届毕业生求职补贴 |
| **租房补贴** | ❌ 无市级统一补贴，需入职特定区县/企业 |
| **生活补贴** | ❌ 无 |
| **面试补贴** | ❌ 无 |
| **青年就业驿站免费住宿** | ✅ 符合条件可申请（外地来京求职青年）|
| **职业技能培训补贴** | ✅ 符合 |
| **就业见习** | ✅ 毕业后 2 年内未就业可申请 |
| **人才保租房（经开区）** | ⚠️ 入职亦庄企业后可申请（租金 70%）|

**结论**：北京对普通应届本科生的**直接补贴极少**，主要依赖企业薪资和个人能力。但平台大、机会多、薪资天花板高。

## 三、天津市 — 就业/人才/实习政策

### 3.1 一次性求职创业补贴

| 项目 | 内容 |
|------|------|
| **补贴名称** | 2026 届毕业生一次性求职创业补贴 |
| **补贴金额** | 据各地标准确定（一般 1,000–3,000 元）|

**你的情况**：如不符合上述困难条件，则 ❌ 无法申请。

### 3.2 企业职工个人社会保险补贴 ⭐

| 项目 | 内容 |
|------|------|
| **政策文件** | 《关于做好企业职工个人社会保险补贴有关工作的通知》（2025 年发布） |
| **有效期** | 延续至 **2026 年 12 月 31 日** |
| **补贴对象** | 毕业年度和离校两年内未就业高校毕业生 |
| **适用企业** | 制造业、建筑业、现代服务业、生活服务业等重点行业的中小微企业 |
| **补贴标准** | 按个人缴费额的 **25%** 给予职工社会保险补贴，补贴期限最长 **12 个月** |
| **申请条件** | ① 与企业签订 1 年以上劳动合同；② 按规定缴纳基本养老保险、基本医疗保险、失业保险 |
| **申请渠道** | "天津公共就业服务网" → 找服务 → 业务领域 → 法人 → 企业职工个人社会保险补贴申报 |
| **发放方式** | 补贴资金拨付到职工个人社保卡账户 |
| **特别说明** | 2025 年符合条件但未及时申领的，可在 2026 年补报 |

**你的情况**：
- 2027 年 6 月毕业后入职天津中小微企业 → ✅ 符合
- 补贴金额：以天津 2026 年社保个人缴费约 1,500–2,000 元/月估算 → 每月补贴约 **375–500 元**，最长 12 个月

### 3.3 "海河英才"计划与落户

| 项目 | 内容 |
|------|------|
| **落户政策** | 符合条件的高校毕业生可在离校前网上申请落户，由公安、人社、教育部门统一审核 |
| **"海河英才"卡** | A/B/C 卡持有人可享受社保、医疗、子女入学、购房、出行等服务 |
| **人才公寓** | 市级人才公寓认定，给予用水、用电、租金优惠 |
| **租房补贴** | 需持"海河英才"卡且符合特定条件，非普惠性 |

**关键结论**：天津对普通应届本科生**无直接租房/生活补贴**，主要通过落户便利和社保补贴吸引人才。

## 十、关键注意事项

### ⚠️ 1. 社保是补贴的「硬门槛」

绝大多数补贴（租房补贴、生活补贴、购房补贴）都要求**连续缴纳当地社保**。作为实习生：
- **实习期**：多数公司不缴纳社保 → **无法享受补贴**
- **转正后**：开始缴纳社保 → **满足补贴条件**
- **策略**：尽量选择能转正或签劳动合同的实习，为毕业后无缝衔接做准备

### ⚠️ 2. 「首次引进」限制

苏州、南京等城市的租房补贴通常要求"首次从外地引进"：
- 如果你在毕业前就在该城市实习并缴了社保，可能被视为"已引进"
- **建议**：实习期间尽量不缴社保，或确认实习社保是否影响正式入职后的补贴资格

### ⚠️ 3. 劳动合同年限要求

多数补贴要求签订 **1 年及以上劳动合同**。短期实习（3 个月）通常不满足。

### ⚠️ 4. 无房证明

租房补贴、购房补贴通常要求申请人在当地无自有住房。与父母共有家庭唯一一套住房的，部分城市允许申请（如南京）。

### ⚠️ 5. 申请时限

| 补贴 | 申请时限 |
|------|----------|
| 面试交通补贴 | 毕业前 1 年内 |
| 租房补贴 | 入职后社保满 6 个月内 |
| 求职创业补贴 | 毕业学年 9 月 1–30 日 |
| 职业技能培训 | 随时（需先报名培训）|

### ⚠️ 6. 江苏省社会保障卡

多个补贴（如求职创业补贴）统一发放到**江苏省社会保障卡**。建议提前办理。

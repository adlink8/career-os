# 三方会审仲裁与一票否决规则 (Consensus & Arbitration Rules)

## 一、 综合评分加权公式

三方子 Agent 独立输出 0~100 分的单项分数后，系统按如下权重合成综合指数：

$$\text{Total Score} = \text{Score}_{\text{ATS}} \times 0.35 + \text{Score}_{\text{HR}} \times 0.30 + \text{Score}_{\text{Tech}} \times 0.35$$

- **ATS 权重 35%**：机器是第一道生死关，决定简历是否能被检索出来。
- **HR 权重 30%**：决定简历是否会被秒刷淘汰或被标记为海投。
- **技术官权重 35%**：决定技术初筛与后续面试的真实转化率。

---

## 二、 三方会审红绿灯裁决机制

| 评审等级 | 判定门槛 | 处置与行动指令 |
| :--- | :--- | :--- |
| 🟢 **PASS（安全放行）** | • 综合总分 ≥ 85 分<br>• 三方评分均 ≥ 80 分<br>• **无任何一票否决项** | **准许投递**。系统解除投递锁定，可在官网点击网申。 |
| 🟡 **WARN（中度风险）** | • 综合总分在 70 ~ 84 分之间<br>• 无致命一票否决项 | **暂停投递**。系统输出《10分钟必改清单》，要求补齐 Missing Keywords 或微调第一项目后，重新提交复审。 |
| 🔴 **FAIL（强制拦截）** | • 综合总分 < 70 分<br>• **或命中任一票否决项** | **绝对禁止网申**。判定为高危盲投或无效海投，阻止任何自动化网申。 |

---

## 三、 一票否决清单（Veto Triggers）

以下任一情况发生，**不看综合总分，直接判定为 🔴 FAIL 拦截**：

1. **【ATS 否决】** 求职意向包含“与”、“/”、“及”（违反 Rule 316 复合兼顾禁令）；
2. **【ATS 否决】** 目标 JD 前 5 大核心技术词覆盖率低于 60%；
3. **【HR 否决】** 简历未按目标 JD 重新定名，使用了其他企业/岗位的旧名称；
4. **【HR 否决】** 在同一企业同时提交多份跨专业简历且内容无针对性适配；
5. **【技术官否决】** 第一主推项目与目标岗位核心职责完全脱节（例如投大模型岗把纯单片机放第一项目）。

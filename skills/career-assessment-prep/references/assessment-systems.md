| 维度 | 数据 |
|------|------|
| 使用公司 | 字节跳动、百度、东北证券、中建二测、多家互联网 |
| 题型 | 言语理解（11题）+ 图形推理（11题）+ 数量关系（11题）+ 资料分析（11题）+ 性格测试（~98题） |
| 限时 | 行测 60-90s/题，性格不限时 |
| 难度 | ★★★★☆ |
| 特点 | 题库大、更新快、题目不重复 |

### 各题型详解

**言语理解**
- 片段阅读：主旨概括、态度理解、细节理解、标题选择、语句排序
- 词语填空：实词/虚词/成语辨析、语境辨析
- 策略：先看选项→再看文段→注意转折词"但是/然而/因此"

**图形推理**
- 平面图形：旋转、翻转、对称、数量变化（点/线/面）
- 空间图形：立体折叠/展开
- 策略：看元素→看位置→看数量→看样式，四步排除

**数量关系**
- 数字推理（找数列规律）
- 数学运算：工程/几何/行程/排列组合/最值/溶液/牛吃草
- 策略：代入法优先，不要死算

**资料分析**
- 文字题 + 图表题
- 策略：先看题目→定位数据→计算，别读全文

**性格测试**
- 98题，不限时
- 策略：一致性+中庸+岗位匹配，不选极端选项

# 行业调研方法论

> 供 `career-industry-research` 各模块查询的调研流程、数据源优先级、时效控制。

## 一、数据源优先级(权威性排序)

### 一级源(官方/权威,优先用)

| 来源 | 类型 | 链接 | 用途 |
|------|------|------|------|
| 中国信通院(CAICT) | 政府智库 | http://www.caict.ac.cn/kxyj/qwfb/ztbg/ | 政策/产业白皮书 |

## 二、调研流程(skill 执行顺序)

```
1. 方向识别
   → 从 profile.yml 提取目标方向
   → 映射到 knowledge/industry-reports/ 的方向文件

2. 数据采集(必做 WebSearch)
   → 搜索权威报告(一级源)
   → 搜索招聘平台岗位数据(三级源)
   → 至少 2 个来源交叉验证

3. 时效校验(KNOW-03)
   → 报告发布日期 < 12 个月
   → 否则标注"数据可能过时,建议核对最新"

4. 趋势判断
   → 应用趋势分类框架(上升/稳定/转型/收缩)
   → 列出驱动因素(利好 + 风险)

5. 决策辅助
   → 摆出有利/不利因素
   → 不替用户决定
```

---

## 三、时效控制规则(KNOW-03 核心)

### 必须刷新的数据

- 行业增长率 / 市场规模
- 岗位数量 / 薪资水平
- 公司融资 / 倒闭数据

### 相对稳定的数据

- 行业基础概念
- 技能栈结构(变化慢)
- 职业发展路径

### 标注规则

每个数据点必须附:
```
{数字} 📅 来源:{机构} {报告名} {YYYY-MM}
```

示例:
```
中国 IoT 市场规模 {X 亿} 📅 来源:艾瑞《2025 中国物联网行业研究报告》2025-09
```

## 四、交叉验证规则

### 单一来源风险

任何单一来源(尤其商业报告)可能有偏差:
- 艾瑞报告倾向乐观(商业利益)
- 招聘平台数据反映"在招"而非"真实需求"
- 社区口碑偏向离职员工(负面偏差)

### 交叉验证策略

至少 2 个独立来源印证同一结论:
- 报告数据 × 招聘数据
- 官方数据 × 社区数据
- 量级数据 × 趋势数据

## 五、与其它 skill 的协同

### 上游

- `career-self-assessment` 输出方向推荐 → 本 skill 的调研对象

### 下游

- 调研结论 → 影响 `career-general-recruit` 的投递策略
- 行业薪资数据 → `career-interview-master` 谈薪参考
- 技能缺口 → `career-learning-path` 学习规划依据

### 协同话术

```
行业调研完成。
建议下一步:
A. 看看这个方向的具体岗位(转 career-general-recruit)
B. 评估你和这个方向的匹配度(转 career-self-assessment)
C. 规划补齐技能(转 career-learning-path)
```

---

## 六、局限性声明(skill 必须告知用户)

- 报告数据有滞后(发布周期 3-6 个月)
- 行业判断基于历史趋势,不保证未来
- 小众方向(如 AI 运维)数据少,判断难度大
- **skill 不输出"一定值得入/一定不值得入"的结论**

## 二、高频危机场景速查

### 场景 1:领导找谈话

**信号:** 领导单独找你,语气严肃

**应对:**
```
1. 不要慌(谈话 ≠ 要辞退)
2. 听完再说(不打断)
3. 复述确认("您说的 X,我理解是 Y,对吗?")
4. 如是批评:
   - 不辩解(先接受)
   - 问具体改进点
   - 给出改进承诺 + 时间表
5. 如是表扬:
   - 感谢
   - 表达继续努力
```

### 场景 2:第一次犯错

**信号:** 操作失误 / 任务出错

**应对:**
```
1. 立即上报(不隐瞒)
   → 越早暴露,损失越小
2. 提供解决方案(不只报问题)
   → "我犯了 X 错,影响是 Y,我建议这样补救 Z"
3. 复盘(事后)
   → 根因 + 防再犯措施
4. 不要过度自责
   → 新人犯错正常,关键是态度
```

### 场景 3:被分配不可能完成的任务

**信号:** 任务量过大 / 难度远超能力 / deadline 不合理

**应对:**
```
1. 不要直接拒绝(显得推诿)
2. 也不要硬扛(做不完更糟)
3. 拆解 + 排优先级
   → "这个任务包含 A/B/C,A 我能做,B 需要协助,C 超出我目前能力"
4. 协商 scope 或 deadline
   → "如果聚焦 A,我能在 X 天完成;全做的话需要 Y 天"
5. 必要时找 mentor 协调
```

### 场景 4:同事不配合

**信号:** 推不动跨部门协作 / 同事拖延

**应对:**
```
1. 先自查(自己要求是否合理/沟通是否清晰)
2. 私下沟通(不当众施压)
   → "这个任务的卡点在 X,你看怎么推进?"
3. 如对方确实忙,协商时间
4. 如对方推诿,留下沟通记录
5. 影响项目时,向上反馈(客观陈述,不带情绪)
```

### 场景 5:加班严重

**信号:** 经常加班到很晚 / 周末也要工作

**应对:**
```
1. 判断原因
   → 自己效率低?任务太多?团队文化?
2. 如自己效率低 → 提升技能(转 career-learning-path)
3. 如任务太多 → 学会优先级管理
4. 如团队文化 → 评估是否可接受
5. 极端情况(007/严重侵占生活)→ 评估是否值得留
```

### 场景 6:感觉融不进团队

**信号:** 午饭没人叫 / 群里没人理 / 团建被忽略

**应对:**
```
1. 主动出击(不要等别人)
   → 主动问"中午一起吃饭吗?"
2. 找共同话题(技术/游戏/美食)
3. 参与团队活动(即使不感兴趣)
4. 观察:是团队排外,还是自己太被动?
5. 给时间(融入需要 1-3 个月)
```

## 三、转正关键节点提醒

### 试用期 1/3 节点(Day 30)

**自查:**
- [ ] 能独立完成常规任务?
- [ ] 知道遇到问题找谁?
- [ ] 至少参加过 1 次团队活动?

**如不达标:**
- 主动找 mentor 沟通
- 调整方法(可能学习方向错了)
- 不要藏着,早暴露早解决

### 试用期 2/3 节点(Day 60)

**自查:**
- [ ] 能 owner 一个任务?
- [ ] 主动提过改进建议?
- [ ] 开始有自己的判断?

**如不达标:**
- 与领导 1v1,对齐期望
- 检查是否被分配了过难的任务
- 主动争取机会

**准备:**
- [ ] 整理 90 天成果(量化)

- [ ] 收集同事反馈
- [ ] 明确下一阶段目标
- [ ] 准备薪资谈判(第一次谈薪机会)

## 四、被辞退的应对(最坏情况)

### 法律权益

- 试用期辞退也需符合《劳动合同法》第 39 条
- 公司需证明"不符合录用条件"(不能随便辞)
- 违法辞退可申请劳动仲裁
- 协商解除通常有 N 或 N+1 补偿

### 应对流程

```
1. 冷静(不要当场签任何文件)
2. 要求书面理由(防扯皮)
3. 评估:是匹配问题 / 能力问题 / 公司问题?
4. 协商:
   → 补偿(N 或 N+1)
   → 离职证明表述(避免负面)
   → 社保公积金结算
5. 立即启动求职(转 career-general-recruit)
6. 复盘原因(下次避免)
```

### 心态调整

- 试用期被辞 ≠ 能力不行(可能是匹配问题)
- 不要否定自己
- 当作一次经验,复盘后继续前行
- 不要空窗太久(立即求职)

## 五、用户专属建议(基于 profile.yml)

### 用户优势(试用期发挥)

- **Python 熟练** → 运维岗稀缺,主动提议自动化
- **真实项目经验** → AWS IoT + 竞赛,展示能力
- **学习能力强** → 在学 K8s/CI-CD,展示上进心

### 用户需注意

- **专升本背景** → 某些公司可能有偏见,用成果说话
- **第一份工作** → 至少做满 1 年,积累经验
- **无生产经验** → 第一周多观察,不急于操作

### 心态建议(profile.yml 显示用户单身/攒钱策略)

- 经济压力小(不急于涨薪)→ 可以接受成长性高的工作
- 长期目标清晰(攒现金流+认知+技能)→ 选对方向比短期薪资重要
- 第一份工作定位为"学技能",不是"赚钱"

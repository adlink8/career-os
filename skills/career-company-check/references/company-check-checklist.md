# 公司背调检查清单

## 必查项（企查查/天眼查）

- [ ] 统一社会信用代码存在
- [ ] 注册资本 ≥ 10 万
- [ ] 实缴资本 ≠ 0（壳公司标志）
- [ ] 成立时间 ≥ 1 年
- [ ] 社保缴纳人数 ≥ 10
- [ ] 无经营异常
- [ ] 无失信记录
- [ ] 无劳动争议诉讼（关键：是否拖欠工资）
- [ ] 法人/股东无频繁变更

## 社媒口碑

- [ ] 脉脉：员工评价 + 加班情况
- [ ] 知乎：相关讨论
- [ ] 看准网：评分和匿名评价
- [ ] V2EX/linux.do：相关讨论

## 面试中反向验证

- [ ] 问：团队规模？（对比社保人数是否一致）
- [ ] 问：技术栈？（是否主流、有无成长性）
- [ ] 问：入职培训？（有没有人带）
- [ ] 观察：办公环境是正规写字楼还是住宅

## 红色底线（命中一条 = 高风险）

1. 社保人数 < 3
2. 有"拖欠工资"判决书
3. 经营异常且未处理
4. 实缴资本为 0
5. JD 薪资与公司规模严重不符

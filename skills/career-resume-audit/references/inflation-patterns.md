# 简历包装夸大模式自查清单

> 改编自 Claycui828/ASu-resume-skills `references/inflation-patterns.md`(转为第一人称自查)。
> 命中任何一条 ≠ 造假,但 = 面试官的拷打入点。逐条对照简历。

## 角色膨胀类

- [ ] **贡献升级**:参与 → 核心;核心 → 主导;contributor → owner(没有明确授权边界)
- [ ] **Owner 作用域外扩**:负责的是某个模块,表述却像负责整个系统
- [ ] **自授 title**:在多个自有平台(简历/主页/博客)重复同一个没有授予方的头衔

## 成果转移类

- [ ] **团队成果归个人**:项目整体指标(用户数/性能/规模)写成"我达成"
- [ ] **平台光环转移**:项目/公司/仓库的 star、排名、品牌暗示成个人能力
- [ ] **复述系统架构代替个人产物**:能画出整个架构图 ≠ 你建了它,能指出"我建的部分"才算

## 指标游戏类

- [ ] **分母切换**:环比增长用同比口径,或转化率换了分母不说
- [ ] **伪精确**:没有测量手段支撑的精确数字("提升 37.2%")
- [ ] **无基线因果**:没有对照组/基线就宣称"因为我做了 X 所以 Y"
- [ ] **时间压缩**:两周试用写成"长期实践"

## 呈现技巧类

- [ ] **学习中说成掌握**:profile 三级的降档是硬规则
- [ ] **规划中写成已落地**:"在做/计划做"写成"已实现"
- [ ] **场景美化**:课设/教程跟做写成"独立项目"(本项目已排除此类,保持)

## 本项目当前已守住的线(审计时复核不退化)

- AI 工具只写"AI 辅助工程",不写"精通 AI"
- K8s/CI-CD/英语保持 learning 级
- 课设(Hadoop 实践、Cisco 实验)不进简历
- "172 测试通过"类无出处数字不用

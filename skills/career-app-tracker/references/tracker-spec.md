# TSV 字段规范

## tracker.tsv 格式

Tab 分隔，UTF-8 编码。

### 字段（Career OS canonical-v2）

| 序号 | 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 1 | 日期 | 是 | YYYY-MM-DD | 2026-06-06 |
| 2 | 公司名称 | 是 | 全称 | XX科技有限公司 |
| 3 | 目标岗位 | 是 | 岗位名 | 运维实习生 |
| 4 | 目标城市 | 否 | 工作地 | 苏州 |
| 5 | 薪资范围 | 否 | k/月 | 4-6k |
| 6 | 企业官网 | 否 | 企业主页 | https://example.com |
| 7 | 校招网申直达链接 | 否 | 申请入口或内推说明 | https://campus.example.com |
| 8 | 当前状态 | 是 | 见下方枚举 | 已投递 |
| 9 | 战略定位与项目匹配备注 | 否 | 与 profile/CV/项目的匹配证据 | 对位 MQTT 项目 |

### 状态枚举

```
待投递/准备网申 → 尚未提交申请
已投递 → 投递后初始状态
简历过筛 → HR 通知简历通过
笔试邀请 → 收到笔试通知
面试邀请 → 收到面试通知
一面 → 完成第一轮面试
二面 → 完成第二轮面试
HR面 → 完成HR面试
Offer → 收到录用通知
已接 → 接受 Offer
已拒 → 拒绝或主动放弃
被拒 → 被公司拒绝
无回复 → 超过 14 天无任何反馈

> 文件前部允许保留 Markdown 统计摘要；自动化只读取以 `日期<TAB>公司名称<TAB>目标岗位` 开头的 canonical-v2 表头及其后数据行。
```

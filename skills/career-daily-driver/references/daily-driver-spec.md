# 每日作战台规范

优先级：已约面/笔试准备 > 已投递跟进 > 高匹配候选岗位核验 > 学习补缺。

统计规则：

- `已投递`、`简历过筛`、`笔试邀请`、`面试邀请`、`Offer` 才进入真实转化统计；
- `重点关注/待投递`、`待投递/准备网申`、`待沟通内推` 只算候选，不算投递；
- 每项行动必须能在 tracker、current-status 或报告表中找到回写位置。

口径说明：tracker.tsv 顶部「统计指标」表按**企业建档口径**（建档数 = 去重企业数；流程中/待回复 = 已投递待回复 + 待沟通内推），与本 spec 的**逐行状态口径**不同。两者冲突时以逐行状态为准，并在阻塞项中提示用户修正统计表。

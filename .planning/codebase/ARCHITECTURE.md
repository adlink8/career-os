## 三层架构(项目核心设计)

```
┌─────────────────────────────────────────────────────────┐
│  Skill 层 (skills/)         — 操作层:"AI 怎么做"        │
│  10 个 SKILL.md,平台中立,定义流程/触发词/输出格式      │

                         │ 读取
┌────────────────────────▼────────────────────────────────┐
│  Knowledge 层 (knowledge/)  — 知识层:"AI 喂什么"        │
│  11 个域 / 28 个内容文件,被 skill 引用,不独立运行      │
└────────────────────────┬────────────────────────────────┘

┌────────────────────────▼────────────────────────────────┐
│  Data 层 (config/ data/ templates/) — 数据层:"你是谁"  │

```

## 关键设计决策

| 决策 | 理由 |
|------|------|
| skill 正文零硬编码 agent 平台 | 多 agent 可移植(WorkBuddy/Claude/Cursor 通用) |
| knowledge 独立成层(不内嵌 skill) | 跨 skill 共享 + 独立更新(如题库刷新不动 skill) |
| 真实数据 gitignored,模板入库 | 隐私保护(DATA-03) |
| 验证靠脚本不靠 CI | 本地优先,零依赖,任何 Windows 可跑 |
| 三层通过相对路径引用 | skill 写 `knowledge/xxx/`,AI agent 按运行时根解析 |

## 架构边界(不做什么)

- ❌ 不是 web 应用 / SaaS(无后端、无数据库、无 API)
- ❌ 不做私有招聘平台爬虫(账号 + 合规风险)
- ❌ 不存储密钥/token(profile.yml 无凭据)
- ❌ 不内嵌特定 agent 平台逻辑(保持中立)

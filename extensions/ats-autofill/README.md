# 网申自动填表助手

帮你把姓名、学校、项目这些**重复信息**填进企业招聘网站（北森、Moka 等）。

- 不用 GitHub
- 不用安装 Python
- 不用安装 Career OS
- **不会替你点「提交」**，填完你自己检查再交

国内下载（推荐）：<https://gitee.com/li-shuoya/career-os-autofill>

当前版本：**1.8.0**　推荐浏览器：**Microsoft Edge**

## 只装插件

1. Chrome / Edge 打开扩展页 → 开发者模式 → 加载已解压目录（本文件夹，能看见 `manifest.json`）
2. 设置页填底稿，或把 JSON 拖进去，点「一键导入并启用」
3. 打开企业网申页：点格子旁边「填入 / 复制」，或 Alt+Shift+F 一键填

给同学看的逐步说明在 Gitee 仓库首页。

## 可选：接到 Career OS

关掉设置页开关后，才会去读本机编排器（专投 / 海投）。没装 Career OS 时请保持开关打开。

# 网申自动填表助手

帮你把姓名、学校、项目这些**重复信息**填进企业招聘网站（北森、Moka 等）。

- 不用 GitHub
- 不用安装 Python
- 不用安装 Career OS
- **不会替你点「提交」**，填完你自己检查再交

国内下载（推荐）：<https://gitee.com/li-shuoya/career-os-autofill>

当前版本：**1.10.2**　推荐浏览器：**Microsoft Edge**

填表按内容库**字段名**对页面标签；旧 `universal` / `application` JSON 只在导入时迁入，不再当填表主路径。

## 只装插件

1. Chrome / Edge 打开扩展页 → 开发者模式 → 加载已解压目录（本文件夹，能看见 `manifest.json`）
2. 设置页是一份**自由模块内容库**：模块名、字段名、正文都能改。也可把 JSON 拖进去（旧 universal 画像会一次性迁入）。点「一键导入并启用」
3. 「一键填充范围」按**模块标题**勾选；要几段经历就在该模块里「添加一段」
4. 打开企业网申页后，需要时再点「自适应配置」（只扫表单项、按折叠分组；标题对不上就并进已有模块，补空字段不覆盖正文）或「用本页上次配置」。**换站不会自动切骨架**
5. 点格子旁小圆点展开「填入 / 复制」，或 Alt+Shift+F 一键填（只写勾选的模块）
6. Moka：必须进入「职位申请」页（地址带 `#/job/…/apply`）。职位详情页没有报名格子，一键会提示先点申请。
7. 白牌网申 / 大厂自建站：打开该页后点插件图标「在当前页启用填表」，允许权限后再一键。不能保证每个自定义下拉都写得进。

给同学看的逐步说明在 Gitee 仓库首页。

## 可选：接到 Career OS

关掉设置页开关后，才会去读本机编排器（专投 / 海投）。没装 Career OS 时请保持开关打开。

# 网申自动填表助手

帮你把姓名、学校、项目这些**重复信息**填进企业招聘网站（北森、Moka 等）。

- 不用 GitHub
- 不用安装 Python
- 不用安装 Career OS
- **不会替你点「提交」**，填完你自己检查再交

国内下载（推荐）：<https://gitee.com/li-shuoya/career-os-autofill>

当前版本：**1.8.9**　推荐浏览器：**Microsoft Edge**

## 只装插件

1. Chrome / Edge 打开扩展页 → 开发者模式 → 加载已解压目录（本文件夹，能看见 `manifest.json`）
2. 设置页填底稿，或把 JSON 拖进去，点「一键导入并启用」
3. 「一键填充范围」勾选要写的类别；实习/项目/职务/证书按需要「添加一段 / 删除」
4. 打开企业网申页：点格子旁边「填入 / 复制」，或 Alt+Shift+F 一键填（只写勾选的类别）
5. Moka：必须进入「职位申请」页（地址带 `#/job/…/apply`）。职位详情页没有报名格子，一键会提示先点申请。
6. 白牌网申 / 大厂自建站：打开该页后点插件图标「在当前页启用填表」，允许权限后再一键。不能保证每个自定义下拉都写得进。

给同学看的逐步说明在 Gitee 仓库首页。

## 可选：接到 Career OS

关掉设置页开关后，才会去读本机编排器（专投 / 海投）。没装 Career OS 时请保持开关打开。

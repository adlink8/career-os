# 四大测评系统对比

> 本文件与 `skills/career-assessment-prep/references/assessment-systems.md` 互补:
> reference 文件偏 skill 执行流程;本文件偏知识查询。
>
> ⚠️ 下表混合了供应商题型概览和社区历史经验；“市占率/公司类型/公司映射”不是企业当前承诺。同一企业会按岗位、地区和年份切换测评组合，当前证据以 `assessment-intelligence.md` 的官方链接和实际邮件为准。

企业与社区的可追溯测评情报见 [`assessment-intelligence.md`](assessment-intelligence.md)，不要把社区“真题回忆”直接当作默认题库。

## 总览表

| 系统 | 市占率 | 使用公司类型 | 难度 | 时长 | 特点 |
|------|--------|------------|------|------|------|
| 北森 | ~60% | 字节/百度/中建/多数互联网 | ★★★★ | ~45min | 题库大、更新快 |
| 智鼎 | ~20% | 移动/光大银行/研究所 | ★★★ | ~50min | 重复率高、时间充裕 |
| SHL | ~10% | 外企/管培 | ★★★★★ | ~25min | 全英文、语言门槛 |
| 赛码 | ~10% | 中小厂 | ★★ | ~40min | 题库小、网上可搜 |

## 题型分布对比

| 题型 | 北森 | 智鼎 | SHL | 赛码 |
|------|------|------|-----|------|
| 言语理解 | 11题 | 13题 | 阅读 | 10题 |
| 图形推理 | 11题 | 4题 | - | 10题 |
| 逻辑推理 | 11题 | 6题 | - | 10题 |
| 数量关系 | 11题 | 5题 | - | 10题 |
| 资料分析 | 11题 | - | - | 10题 |
| 性格测试 | ~98题 | 30min | - | - |
| 英语 | - | - | 听说读写 | - |

## 限时对比

| 系统 | 每题时限 | 总时间 | 策略 |
|------|---------|--------|------|
| 北森 | 60-90秒 | ~45min | 速度优先,难题跳过 |
| 智鼎 | ~50秒 | 30min(行测)+ 30min(性格) | 时间相对充裕 |
| SHL | 按系统 | ~25min | 语言门槛 > 时间压力 |
| 赛码 | 充裕 | ~40min | 网上可搜答案 |

## 系统识别速查(用户说公司名 → 判断系统)

| 用户提到 | 大概率系统 |
|---------|----------|
| 字节/百度/网易/中建/东北证券 | 北森 |
| 移动/光大/29所/研究所 | 智鼎 |
| 外企/管培/联合利华类 | SHL |
| 中小厂/不知名公司 | 赛码或自研 |
| 银行(除光大) | 多为北森或自研 |

## skill 调用提示

- skill 诊断模块读取本表,根据用户提到的公司判断系统
- 然后从对应系统的题型分布抽取模拟题

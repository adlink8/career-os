## 一、Linux 基础(必考)

### Q1:如何查看系统负载?load average 三个数字什么意思?

- **考点:** 系统监控基础
- **答案要点:**
  - `uptime` / `top` / `w` 查看
  - 三个数字 = 1/5/15 分钟平均负载
  - 单核 > 1 表示过载,多核除以核数
- **追问陷阱:** "load 高但 CPU 不高是什么原因?" → IO 等待

### Q2:进程和线程的区别?

- **考点:** 操作系统基础
- **答案要点:**
  - 进程 = 资源分配单位,线程 = CPU 调度单位
  - 同进程线程共享内存,进程间隔离
  - 线程切换成本低于进程

### Q3:常用文件权限 755 / 644 什么意思?

- **考点:** 权限模型
- **答案要点:**
  - 三组 rwx(4/2/1)= 所有者/组/其他
  - 755 = rwxr-xr-x(目录常用)
  - 644 = rw-r--r--(文件常用)

### Q4:如何查找占用 80 端口的进程?

- **答案:**
  - `netstat -tlnp | grep :80`
  - 或 `lsof -i :80`
  - 或 `ss -tlnp | grep :80`

## 二、网络(必考)

### Q5:TCP 三次握手为什么不是两次?

- **考点:** TCP 基础
- **答案要点:**
  - 两次握手无法确认客户端的接收能力
  - 无法防止历史连接(已失效的 SYN)
  - 三次 = 双方都确认对方能收能发

### Q6:HTTP 和 HTTPS 的区别?

- **答案要点:**
  - HTTPS = HTTP + SSL/TLS
  - HTTPS 用 443,HTTP 用 80
  - HTTPS 加密传输,需要证书

### Q7:如何排查网络不通?

- **考点:** 故障排查思维
- **答案要点(分层排查):**
  1. 物理层:网线/网卡灯
  2. 链路层:`ip addr` 看 IP
  3. 网络层:`ping 网关` → `ping 8.8.8.8`
  4. 传输层:`telnet IP 端口`
  5. 应用层:`curl` / DNS 解析

## 三、Docker(常考)

### Q8:Docker 和虚拟机的区别?

- **答案要点:**
  - Docker 共享内核,VM 各自完整内核
  - Docker 启动秒级,VM 分钟级
  - Docker 资源占用少

### Q9:Docker 镜像分层原理?

- **答案要点:**
  - 联合文件系统(UnionFS)
  - 每层只读,容器层可写(Copy-on-Write)
  - 共享层节省空间

### Q10:如何让容器开机自启?

- **答案:** `docker run --restart=always` 或 `--restart=unless-stopped`

## 四、故障排查(用户强项,重点准备)

### Q11:服务器 CPU 飙高怎么排查?

- **考点:** 这正是用户竞赛经验对口的能力
- **答案要点:**
  1. `top` 找占 CPU 高的进程
  2. `top -H -p PID` 找高 CPU 线程
  3. `strace -p PID` 看系统调用
  4. 判断:业务代码 / GC / 死循环 / 被入侵挖矿

### Q12:磁盘满了怎么处理?

- **答案要点:**
  1. `df -h` 确认满了
  2. `du -sh /* | sort -rh` 找大目录
  3. 清理日志 / 临时文件 / 不用的镜像
  4. 不要直接删,先确认是不是业务文件

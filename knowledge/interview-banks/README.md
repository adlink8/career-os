## 文件清单

- `ops-interview-questions.md` — 运维/技术支持高频面试题
- `iot-interview-questions.md` — IoT 方向面试题
- `behavioral-bank.md` — 行为面试题库(STAR 回答模板)
- `reverse-questions.md` — 反向提问清单(面试官问你有什么问题)

## skill 调用提示

- 题库以**理解 + 表达**为目标,不是背答案
- 用户的方向(运维/IoT)优先用对应题库
- 系统设计题对初级运维较少,但了解概念有加分

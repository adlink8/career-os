# industry-reports 知识域

> **用途:** 供行业调研(步骤 2,skill 待建)调用,提供中文互联网行业报告的高质量索引源。
> **更新方式:** 季度刷新。报告数据有时效性,**使用前必须核对发布日期**(见 KNOW-03)。
> **消费 skill:** `skills/career-industry-research/`(未创建)

## ⚠️ 数据时效声明(KNOW-03)

行业报告时效性强,**本目录任何具体数字使用前必须满足**:
1. 报告发布日期 < 12 个月
2. 引用时必须标注报告名 + 发布机构 + 发布日期
3. skill 输出时必须附 `📅 数据时效:YYYY-MM(报告)` 标签

## 关键趋势(需定期校验)

### IoT 平台运维

- **驱动:** 工业互联网 + 智能制造 + 智慧城市政策
- **岗位增长点:** 设备接入运维、MQTT/CoAP 协议运维、边缘计算
- **技能溢价:** 懂嵌入式通信 + 云平台的复合型人才薪资高于纯运维
- **数据来源核对:** 艾瑞《中国物联网行业研究报告》、信通院《物联网白皮书》

### 运维转型

- **传统运维 → DevOps/SRE**:趋势明确,纯手工运维岗位在减少
- **技能补齐建议:** Docker + Kubernetes + CI/CD 是必修
- **数据来源核对:** roadmap.sh DevOps 路线、Stack Overflow Developer Survey

### AI 运维(AIOps / LLMOps)

- **新兴方向:** RAG 管道维护、LLM 部署运维、Agent 平台运维
- **门槛:** Python + Docker + 向量库,本项目用户已具备基础
- **数据来源核对:** 各招聘平台 JD 关键词频率(需实时搜索)

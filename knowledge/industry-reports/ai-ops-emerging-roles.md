## 新兴岗位画像

### 1. AI Agent 运维 / RAG 管道维护

- **岗位关键词:** AI 运维、LLM 工程助理、RAG 管道、Agent 平台
- **核心技能:** Python + Docker + 向量数据库(Milvus/Pinecone)+ RAG 框架(LangChain/LlamaIndex)
- **加分项:** Kubernetes、模型部署(vLLM/Ollama)、可观测性
- **薪资带:** 见 `salary-data/`(需刷新)
- **用户匹配度:** 高(profile.yml 有 AI-Memory 项目经验)

### 2. LLMOps / MLOps

- **岗位关键词:** LLMOps、模型部署、推理服务运维
- **核心技能:** 模型服务化、GPU 资源管理、监控
- **门槛:** 较高,通常需要 ML 基础
- **用户匹配度:** 中(需补 ML 基础)

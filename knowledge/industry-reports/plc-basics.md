# PLC 速查卡：是什么、为什么存在、有多普及、你要懂到哪

> 创建：2026-09-07
> 关联：`manufacturing-computer-layers.md`（ISA-95 分层与协议速查）
> 目标：回答「PLC 是不是硬件层」「PLC 是什么」「应用有多广」，并界定求职者需要掌握的程度。

---

## 一、先纠正："这是不是就是硬件层"

**不完全是。准确的分层是这样：**

| 层 | 是不是纯硬件 | 说明 |
|----|------------|------|
| L0 现场设备 | **是** | 传感器、电机、阀门、机床——不会编程，只是执行 |
| **L1 PLC / DCS** | **不是** | **可编程的专用计算机**。硬件外壳 + 实时固件 + 用户程序 |
| L2 SCADA / HMI | 不是 | 工控机上跑组态软件 |

**PLC 是硬件形态的计算机。** 它有 CPU、内存、操作系统（实时 OS），跑用户写的程序。只是长得像一块 DIN 导轨上的铁盒子，没有屏幕、键盘、风扇、硬盘。

**用你熟悉的东西类比：** PLC 之于工厂 ≈ ESP32 之于你的 AWS IoT 项目。开发板是硬件，但你在上面写固件、它按你的逻辑跑。区别是 PLC 是工业加固版，而且用梯形图而不是 C/Python 编程。

**更重要的认知：工业界不用"硬件层/软件层"划分，用 OT/IT 划分。** PLC 是 OT 侧最接近软件的那一层。别在面试里说"硬件层"，这个词会暴露你没进过工厂。

## 二、PLC 是什么

**全称：** Programmable Logic Controller，可编程逻辑控制器。

**一句话定义：** 为工业环境加固、用于控制生产过程的专用计算机。

### 诞生故事（这段比定义更有用）

| 时间 | 事件 |
|------|------|
| 1968.06 | 通用汽车 Hydra-Matic 自动变速箱部门发布 **4 页纸招标书**（后称"通用十条"），要一个能替代继电器柜的固态控制器 |
| 1969 | 三家应标：DEC（PDP-14）、3-I（PDQ-II）、Bedford Associates（**Modicon 084**） |
| 1969.11 | GM 接收首批 PLC，一次采购 100 万美元 |
| 1979 | Modicon 为自家 PLC 发明 **Modbus** 协议 |
| 1993.12 | IEC 61131-3 标准发布，确立五种编程语言 |

**痛点是什么：** 60 年代汽车每年改型，产线控制逻辑写在继电器柜的**物理接线**里。改一次逻辑要重新接线、重画图纸，产线停几天。一个继电器坏了，电工要对着图纸一根根查线。

**Modicon 084 为什么赢（关键）：**

DEC 的 PDP-14 是第一个交付的原型机，性能也不差，但改程序要把内存板寄回原厂，往返一周。3-I 的 PDQ-II 要用纸带电传打字机改程序，只有计算机部门的人会。

**Modicon 084 胜在"梯形图"——一种长得跟继电器原理图一模一样的编程语言。**

当时的维护人员是电工不是程序员，他们看懂电路图，看不懂代码。Modicon 让电工**不用重新培训**就能上手。

**这个设计决策的启示（重要）：**

> **OT 世界的第一原则是"迁就现场的人"，不是"追求技术先进"。**

这解释了为什么工厂里还有 WinXP、为什么梯形图五十年没被淘汰、为什么很多"明明有更好方案"的技术推不动——**OT 侧换技术的成本不在技术，在人的再培训。**

你在面试里能说出这一点，比背十个协议名都值钱。

## 三、工作原理：循环扫描

```
读全部输入 → 执行用户程序 → 写全部输出 →（回到开头，永不停止）
   1ms          1~100ms          1ms
```

**一个扫描周期通常 1~100 毫秒。** 上电后无限循环，直到断电。

**关键差异：这是"硬实时"（hard real-time）。** 输出必须在限定时间内响应输入，否则会导致非预期动作——比如机械手该停的时候没停。维基对 PLC 的定义里明确写了这一点。

**对比你的常识：** 你的 Python 脚本 GC 停顿 200ms 无所谓；PLC 晚 200ms 可能撞机。

## 四、为什么不用普通电脑 / 树莓派替代

| 维度 | 普通 PC / 树莓派 | PLC |
|------|----------------|-----|
| 抗干扰 | 无 EMC 防护，车间电机启停就串扰 | 工业级 EMC 认证 |
| 温度 | 0~40℃ | **-20~60℃**，部分更宽 |
| 实时性 | 通用 OS，有 GC/调度抖动 | 实时 OS，确定性扫描 |
| 供电 | 220V 干净市电 | 24V 直流，容忍波动 |
| 结构 | 风扇、硬盘、插槽（会松） | 无风扇无硬盘，DIN 导轨，端子接线 |
| 生命周期 | 3-5 年停产 | **10-20 年供货**（产线要备件） |
| 安全认证 | 无 | SIL / IEC 61508 功能安全 |
| 编程门槛 | 需要程序员 | 电工能看懂梯形图 |

**一句话：PLC 贵在"可靠性 + 长供货 + 电工可维护"，不贵在算力。** 它的 CPU 性能可能还不如你的手机。

## 五、IEC 61131-3 五种编程语言

| 语言 | 缩写 | 形态 | 谁在用 |
|------|------|------|--------|
| **梯形图** | LD | 像电路原理图 | **最主流**，电工/电气工程师 |
| 功能块图 | FBD | 像数字电路框图 | 过程控制 |
| 顺序功能图 | SFC | 像流程图/状态机 | 顺序控制 |
| 结构化文本 | ST | 像 Pascal/C | 复杂算法 |
| 指令表 | IL | 像汇编 | 已边缘化 |

**你只需要知道 LD 是主流、ST 长得像 Pascal 就够了。** 五种名字能报出来是加分，报不出来不扣分。

## 六、应用广泛程度

### 全球

- **年出货量超 3850 万台**（2025，不同口径一致）
- 小型 PLC 占出货量 65%+，但大型高端 PLC 贡献收入 48%+
- 市场规模：117 / 126.6 / 187.3 亿美元（三家机构口径差异大）

| 三个皮匠报告 | 428.6 亿元 |

### 应用行业（华经）

**跟常州直接相关的：** 新能源（锂电、光伏）、新能源汽车、3C、物流仓储——全是常州的主导产业，全是 PLC 重灾区。

## 七、一个能串起来的点

**Modbus 是 Modicon 在 1979 年为自家 PLC 发明的通信协议。**

Modicon（Modular Digital Controller）→ 1979 年推出 Modbus → 后来成为最通用的工业开放协议 → Modicon 品牌 1977 年卖给 Gould，后归**施耐德电气**。

**所以昨天那张协议卡的来龙去脉是：**

> 为了替代继电器柜发明 PLC → 为了不让电工重新培训发明梯形图 → 为了让 PLC 之间能通信发明 Modbus → Modbus 太简陋（只有寄存器地址没有语义），后来才出现 OPC UA。

**这条线索讲出来，面试里就是"懂行"和"背过名词"的区别。**

## 八、你需要懂到什么程度

**不要做的：**
- 不要学梯形图编程（那是电气工程师的活，学了你也不会被招去做这个）
- 不要买 PLC 硬件（几百到几千块，用不上）
- 不要背型号参数

**必须能说的三句：**

1. **"PLC 是工业加固的可编程控制器，不是硬件层——它有 CPU 和实时系统，跑的是梯形图。"**（纠正"硬件层"认知）
2. **"它的工作方式是毫秒级循环扫描——读输入、跑程序、写输出，硬实时，所以不能当普通服务器对待。"**（体现你懂 OT 的时间尺度）
3. **"我负责的是它上面那一段：把 PLC 采到的数据通过网关接出来上云。现场总线和梯形图不是我的活，我的活是对接。"**（划定边界 + 定位自己）

**加分项（说了就赢）：**
- "梯形图之所以五十年没被淘汰，是因为它让电工不用重新培训——OT 侧换技术的成本在人不在技术。"
- "IT 是 CIA（机密性>完整性>可用性），OT 是 AIC（可用性第一）。"

## 九、证据强度

- **强**：PLC 诞生史（1968 GM Hydra-Matic 招标、1969 Modicon 084、Dick Morley）、循环扫描机制、硬实时定义、IEC 61131-3 五种语言、Modbus 由 Modicon 于 1979 年推出 —— 多源一致，含维基与行业媒体。
- **中等**：中国市场份额与国产化率（MIR 睿工业、华经产业研究院数据经二手转述，但结构一致）。
- **弱（不可用）**：中国 PLC 市场规模绝对值（95 亿 / 170 亿 / 428 亿三源打架）、中大型 PLC 国产化率（1-2% vs 18.76% 冲突）、全球市场规模（117 / 126.6 / 187.3 亿美元）。

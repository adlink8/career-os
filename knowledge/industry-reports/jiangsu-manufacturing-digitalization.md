# 江苏制造业基地：被漏掉的雇主池

> 建立时间：2026-09-07
> 触发：用户自问「我的眼界是不是应该放宽一点，不应该只盯着回来，明明我身处江苏制造业基地」
> 结论：**该放宽，但正确的放宽方向不是「多投几个城市」，是「换雇主池」——从乙方 IT 服务商，换到甲方制造业本体。**

### 2.2 政策直接点名了你的赛道

市工信局局长原话（「十五五」发布会）：

> 对规上工业企业**全面开展 AI 应用诊断**……找准研发设计、生产管理、产品质检、**设备运维**等环节的赋能切入点。
>
> 推出「模型即服务」「智能体即服务」的轻量化模式，先从生产质检、**设备运维**、供应链管理这几个最「痛」的点入手。

**「设备运维」被明文列为 AI+制造的四个切入点之一。**

→ **7000+ 家规上工业企业要被逐个做数字化诊断，每一家都需要懂设备联网、数据采集、边缘网关、监控告警的人。这就是需求池。**

## 三、制造业里的岗位叫什么（不是「技术支持工程师」）

| 岗位名 | 职责 | 薪资 |
|---|---|---|
| **智能制造系统运维员**（新职业） | 智能工厂系统数据采集、设备状态监控、故障诊断、预防性维护、系统优化 | 一线 7-12k，持证上浮 10-20% |
| **数字化运维工程师** | MES/WMS/SCADA/IIoT 平台部署、服务器与工控机上架、工业网络 VLAN/防火墙、Modbus 等接口联调、CentOS/国产 OS、Shell/Python 脚本 | 南京 150-500 人企业实例，要求 3 年经验 |
| **设备运维数字化工程师** | SCADA/MES/EAM/PLC-HMI 数据集成、设备运行/报警/故障数据分析、PHM 预测性维护、AI 辅助故障诊断 | 远景动力等（要求 5 年经验） |
| **MES/ERP 实施工程师** | 制造执行系统部署、配置、二次开发、用户培训、数据对接 | 新一线 8-15k |
| 工业机器人调试/运维 | 机器人示教、编程、调试、维护 | 8-15k，持证 12-20k |

**关键：南京「数字化运维工程师」那条 JD 与用户技能栈重合度极高** —— TCP/IP、华为/华三网络设备配置、服务器 RAID、CentOS、Shell/Python、工业控制网隔离、Modbus 接口测试。**缺的只是年限。**

## 四、这对你为什么是好事（四条）

1. **甲方制造业的数字化岗不在校招体系里。** 它们走社招、内推、本地招聘、猎头——正好是你想走的路，没有测评、没有群面。
2. **不看你会不会算法，看你能不能让设备连上。** 制造业招数字化的人，判断标准是「能不能组网、能不能让 PLC 数据出来、能不能看懂报警日志」，不是 LeetCode。
3. **你的技能栈在这里是稀缺的，在互联网是过剩的。** Linux / Docker / MQTT / 网络 / Python / 云接入 —— 互联网大把这批人，制造业工厂里很少。
4. **地理上不是三个城市，是一条线。** 沪宁线常州—无锡—苏州—上海 + 南京，高铁 30-60 分钟。你不需要搬家就能覆盖这个带。

## 五、必须承认的代价与缺口（别乐观过头）

### 5.1 真实缺口：OT 侧不会

制造业数字化岗的 JD 反复出现这些词，用户目前**基本没有**：

| 缺口 | 说明 |
|---|---|
| **PLC**（西门子/三菱/欧姆龙） | 制造业的数字化的源头，不会 PLC 就读不到设备数据 |
| **Modbus / OPC UA / Profinet** | 工业现场总线协议，跟 MQTT 是不同层 |
| **SCADA / MES / 组态软件** | 上位机系统，不是 Docker 那套 |
| 工业网络（VLAN 隔离、工控网/企业网分区） | 有网络基础，但缺工业场景 |

**这不一定是阻断性缺口**——很多岗位是「IT 侧 + OT 侧配合」，招 IT 背景进去补 OT。但面试时会被问，需要能说清楚「我懂数据怎么从设备到云，PLC 那层我可以学/我有同事配合」。

**最低成本补法**：搞懂 MQTT vs Modbus vs OPC UA 的分层关系（各在哪一层、解决什么问题），能画一张「设备 → 网关 → 边缘 → 云平台」的架构图。这一步半天能做完，但能让面试从「完全不懂」变成「知道边界在哪」。

### 5.2 其他代价

- **多数岗位要求 3-5 年经验**，应届入口窄（和中小厂一样的问题）
- 薪资新一线 7-12k，**不是 15k**。但高于此前下调的中小厂 5.5-7k 口径
- 工作场景在厂区/车间，可能有出差、现场调试、配合产线停机的加班窗口
- 制造业 IT 部门通常人就 1-3 个，没人带教，全靠自己摸索

```
常州/无锡/苏州/南京 + 以下任一：
  数字化运维
  智能制造 运维
  设备联网 / 设备数据采集
  MES 实施
  SCADA
  工业互联网 实施
  智能工厂 运维
  工业网络 工程师
```

搜**公司名**时，用这批（制造业本体，不在现有名录里）：

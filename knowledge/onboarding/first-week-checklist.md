# 入职第一周清单

> 第一周的目标不是"做出成绩",而是"搞清楚环境 + 留下靠谱印象"。

## Day 1:报到与环境

### 行政

- [ ] 提交入职材料(身份证/学历/银行卡/体检报告)
- [ ] 签劳动合同(**仔细看**:试用期/薪资/竞业/保密)
- [ ] 领工牌/电脑/账号
- [ ] 录指纹/打卡系统

### 技术环境

- [ ] 申请各类账号:VPN/Jira/Git/Wiki/邮箱
- [ ] 配置开发机(装系统/装软件/配环境)
- [ ] 克隆代码仓库/拉取配置
- [ ] 跑通本地环境(第一个 milestone!)

### 人际

- [ ] 记住直属领导 + mentor 名字
- [ ] 认识同组同事(主动打招呼)
- [ ] 加团队群(工作群/吃饭群)
- [ ] 了解午餐怎么解决(食堂/外卖/拼单)

## Day 2-3:熟悉业务

- [ ] 读团队 Wiki / 文档
- [ ] 了解公司业务(做什么/卖给谁/怎么赚钱)
- [ ] 了解你的岗位在业务链中的位置
- [ ] 梳理系统架构图(运维岗重点)
- [ ] 列出不懂的名词,集中问 mentor

## Day 4-5:小任务上手

- [ ] 接一个简单任务(改文档/小 bug/巡检)
- [ ] 跟着 mentor 走一遍完整流程
- [ ] 第一次提 PR / 提交工单
- [ ] 第一次参与站会/周会

## 第一周避坑

### ❌ 不要做

- 不要装懂(不懂就问,第一周问问题最正常)
- 不要迟到早退(第一印象)
- 不要拒绝同事邀约(午饭是融入团队的关键)
- 不要急于表现(第一周做错事比不做更糟)

### ✅ 应该做

- 多问"为什么"(理解业务逻辑)
- 做笔记(同样的问题不问第二遍)
- 主动汇报进度(让领导知道你在推进)
- 观察团队节奏(什么时候忙/什么时候松)

## 第一周必问 mentor 的问题

1. "我们团队的核心职责是什么?"
2. "我这个岗位前 3 个月主要做什么?"
3. "遇到问题应该找谁?"
4. "代码/文档在哪看?"
5. "考核标准是什么?"
6. "团队习惯用什么沟通工具?"

## 用户专属(运维岗)

运维新人第一周额外关注:
- [ ] 拿到服务器列表/IP/账号
- [ ] 了解监控大屏在哪看
- [ ] 熟悉告警渠道(钉钉/企微/邮件)
- [ ] 看历史故障工单(学习排障模式)
- [ ] 确认值班安排(是否需要 oncall)

# 公司红旗风险库

> 背调时逐项核查,命中任意 P0 红旗直接亮红灯。

## P0 红旗(命中 = 高风险,建议直接放弃)

| # | 红旗 | 判断依据 | 数据来源 |
|---|------|---------|---------|
| 1 | 社保人数 < 3 | 工商社保数据 | 企查查/天眼查 |
| 2 | 有"拖欠工资"判决 | 裁判文书 | 中国裁判文书网 |
| 3 | 经营异常且未处理 | 工商状态 | 企查查/天眼查 |
| 4 | 失信被执行人 | 法院名单 | 企查查/天眼查 |
| 5 | 实缴资本 = 0 | 工商数据 | 企查查/天眼查 |
| 6 | 要求缴纳培训费/押金 | 招聘流程 | **诈骗**,立即放弃 |
| 7 | 要求去非主流 APP 面试 | 招聘流程 | **诈骗**,立即放弃 |
| 8 | 扣押身份证/毕业证 | 入职要求 | **违法**,立即放弃 |

## P1 警告(需进一步确认,不直接否决)

| # | 警告 | 判断依据 | 处理 |
|---|------|---------|------|
| 1 | 成立不到 2 年 | 工商成立日期 | 追问融资/盈利情况 |
| 2 | 频繁法人/股东变更 | 工商变更记录 | 追问原因 |
| 3 | 参保人数与招聘规模严重不符 | 对比 JD 数量 | 可能是中介或壳 |
| 4 | 注册地址是住宅/虚拟地址 | 工商地址 | 实地或地图核查 |
| 5 | 薪资范围过宽(如 4-30k) | JD | 实际通常取下限 |
| 6 | 加班描述模糊/强调"抗压" | JD | 面试时追问作息 |
| 7 | 大量劳动仲裁记录 | 裁判文书 | 即使已结案也警示 |

## P2 观察(行业常态,不一定是坑)

| 现象 | 说明 |
|------|------|
| 创业公司(融资 A 轮前) | 风险高但成长快,看个人偏好 |
| 外包/驻场 | 技术成长有限但稳定,适合攒经验 |
| 996 | 互联网常态,看个人接受度 |
| 大小周 | 介于 996 和双休之间 |

## 行业特定风险

### 互联网/IT

- "技术合伙人"头衔招应届 = 想白嫖
- "高薪 15-30k"招应届 = 通常 15k,且 996

### 物联网/硬件

- 硬件公司看融资轮次(B 轮以下风险高)
- 问清楚是自研产品还是项目外包

### 外企 IT Support

- 确认是否真的是外企(很多"外企"实际是国人注册的离岸公司)
- 看社保公积金是否按实际工资交

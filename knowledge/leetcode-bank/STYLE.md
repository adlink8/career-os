## 文风硬规矩

1. **全白话**：解释代码行像对人说话，"这行是把数组倒进一个自动去重的袋子"✓，"初始化哈希集合以供查询"✗。
2. **比喻可用但不硬凹**：草稿纸(set)、换盒子(=)、翻页查(O(n)) vs 按地址直达(O(1))——沿用既有比喻体系。
3. **提示三档话术**：1 档给方向不给名词；2 档给名词不给用法；3 档给中文步骤不给代码。任何一档都不出现 Python 代码。
4. **逐行解析逐行写**：参考代码有几行就有几条解析，一行不许跳。空行跳过。
5. **坑清单要真实**：优先收录真实初学者踩过的（`= 是覆盖不是放入`、`return 写进循环`、`else 悬空`、`{}` 是字典不是集合、缩进错位、变量名打架）。
6. **复杂度必须讲**：每题对账第 3 问给出暴力 vs 正解的对比和一句"为什么"。
7. Python 统一 Python3，函数签名照 LeetCode 默认模板（`def xxx(self, ...) -> ...:`）。

## 使用纪律（和陪练协议一致）

1. 做题顺序按上面目录；同模式连做 3 题，提示档必须降到 0-1，否则同模式加做。
2. 每题做完错题本记一行（含最高提示档）；T+1 盲写卡点步、T+3 整题盲写。
3. 纯检验卷在每周日或模式做完 3 题后抽查用，**不是替代陪练流程的捷径**。
4. 两道 medium 是试水加餐：easy 全部通关（陌生 easy 20 分钟盲写通过）之前不碰。

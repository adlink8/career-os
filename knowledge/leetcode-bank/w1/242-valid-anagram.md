# LC242 有效的字母异位词（简单）

> 一句话考点：两个词的字母账本能不能对上 | 模式：哈希计数（dict，一加一减）

## 题面

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的**字母异位词**（即两个字符串包含的字母和每个字母的出现次数都完全相同）。

```text
示例 1：s = "anagram", t = "nagaram" → true
示例 2：s = "rat",     t = "car"     → false
```

约束：`1 <= s.length, t.length <= 5 * 10^4`，`s` 和 `t` 仅包含小写字母。

进阶：如果输入字符串包含 Unicode 字符呢？你能否调整你的解法来应对这种情况？

```python

```

<details><summary>💡 提示第 1 档·方向（点开前先自己想 3 分钟）</summary>

"异位"= 字母一样、顺序打乱。顺序不重要，那什么重要？**每种字母各出现了几次**。想想记账：拿到第一个词，每见一个字母往账本上记一笔"多一个"；拿到第二个词，每见一个字母划掉一笔"少一个"。最后什么样才算"两个词是亲兄弟"？——账本上每一笔都正好是零，不多不少。
</details>

<details><summary>💡 提示第 2 档·模式点名</summary>

用哈希家族的 dict（键值对柜子）当**计数账本**：键是字母，值是它出现的次数。s 负责加账，t 负责销账，最后验收全零。
</details>

<details><summary>💡 提示第 3 档·步骤点破（卡死 15 分钟才许开）</summary>

1. 长度不一样，直接交卷 false——账都对不上，不用记了；
2. 造一个空账本；
3. 走第一个词：每见一个字母，账本里它的次数加一（第一次见到要当"从零开始"处理，不能问一个没记过的字母要次数）；
4. 走第二个词：每见一个字母，它的次数减一；
5. 最后逐项验收：任何一格不是零，交 false；全是零，交 true。
</details>

<details><summary>📝 三句口述参考</summary>

1. 遍历什么：先遍历 s 的每个字符，再遍历 t 的每个字符。
2. 记录什么：一个 dict，键是字母，值是"加账减账后的净次数"。
3. 怎么判断/返回：s 阶段每字母 +1，t 阶段每字母 -1；最后所有格子的值全为 0 → true，有任何一格不是 0 → false。
</details>

<details><summary>🔍 参考实现 + 逐行解析</summary>

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        freq = {}
        for c in s:
            freq[c] = freq.get(c, 0) + 1
        for c in t:
            freq[c] = freq.get(c, 0) - 1
        for v in freq.values():
            if v != 0:
                return False
        return True
```

- 第 3-4 行 `if len(s) != len(t): return False` —— 提前止损：字母总数都不同，绝不可能是异位词。这行不写也能对（后面验收会兜住），但少走两个循环。
- 第 5 行 `freq = {}` —— 造一个空账本，键放字母，值放次数。
- 第 6-7 行 `for c in s: freq[c] = freq.get(c, 0) + 1` —— 给 s 记账。`freq.get(c, 0)` 的意思是"查这个字母记了几次，没记过就当 0"——**必须用 get**：直接写 `freq[c]`，问一个账本里没有的字母要次数会当场 KeyError 报错。第一次遇到 'a' 时就是 `0 + 1 = 1`。
- 第 8-9 行 `for c in t: freq[c] = freq.get(c, 0) - 1` —— 给 t 销账，同样是 get 兜底。反过来写成 +1 就变成"两个词的字母全堆一个账本"，验收永远过不了。
- 第 10-12 行 `for v in freq.values(): if v != 0: return False` —— 逐格验收，账本里有任何一格不是零（多一个或少一个字母）就交 false。注意这个 return 在循环**里面**——发现一笔坏账当场叫停。
- 第 13 行 `return True` —— 在 for **外面**，所有格子都验完都是零才有资格说 true。写进循环里，验到第一格就草率交卷了。
</details>

<details><summary>🪤 常见坑（按杀伤力排序）</summary>

1. **`freq[c] = freq[c] + 1` 遇新字母 KeyError**：现象——处理第一个字母就崩。病因：字典里没有的键不能直接读。修复：`freq.get(c, 0) + 1`，get 带默认值兜底。
2. **验收写成只查正数**：现象——"rat" vs "raa" 误判 true。病因：只写了 `if v > 0`，漏了减成负数的格子（t 比 s 多的字母）。修复：`!= 0` 两个方向一起抓。
3. **return True 写进验收循环**：现象——没验完就交卷。病因：一格是零不代表全部是零。修复：True 只能循环外返回。
4. **`=` 和 `+` 打架**：现象——每个字母次数都是 1，丢失累计。病因：写成 `freq[c] = 1` 是覆盖（换盒子），不是累加。修复：用 `freq.get(c, 0) + 1` 在旧值基础上加。
</details>

<details><summary>🎯 对账五问（做完再展开）</summary>

1. 第一个卡点通常在"第一次访问字典新键就报错"——卡在不会用 get 带默认值，不是不会想思路。
2. 最容易漏的动作：减账阶段也要用 `get(c, 0)`（t 里可能有 s 没有的字母）和验收用 `!= 0` 而不是 `> 0`。
3. 为什么快：暴力是每个字母去另一个词里翻页找 + 划掉标记，O(n²)；账本一加一减各走一遍，O(n)。一句话：计数把"反复比对"变成"记账 + 一次验收"。
4. 信号词："字母出现次数相同""打乱顺序""每个字符恰好用一次"→ dict 计数。
5. 变式：找第一个不重复的字符？（还是计数，记完再按原顺序查第一个值为 1 的。）判断能否由重排变成回文？（计数后统计奇数次字母的个数。）
</details>

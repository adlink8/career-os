# LC14 最长公共前缀（简单）

> 一句话考点：像对表格一样，一列一列往下比，第一列对不齐就收工 | 模式：字符串纵向扫描

## 题面

编写一个函数来查找字符串数组中的**最长公共前缀**。

如果不存在公共前缀，返回空字符串 `""`。

```text
示例 1：strs = ["flower","flow","flight"] → "fl"（三串都以 "fl" 开头，第三列 f/l/o 就分叉了）
示例 2：strs = ["dog","racecar","car"]    → ""（第一列就不一致，公共前缀为空）
```

约束：`1 <= strs.length <= 200`，`0 <= strs[i].length <= 200`，`strs[i]` 仅由小写英文字母组成。注意约束里有**空字符串**。

```python
class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:
```

把几个单词**竖着排**写在纸上，像对表格：第 1 列是不是全同一个字母？第 2 列呢？往下比到第一列出现"不一致"或者某个单词提前到头为止——从最上面到收工前那几行拼起来就是答案。竖着比，还是横着一个串一个串比？哪种更好想？
</details>

<details><summary>💡 提示第 2 档·模式点名</summary>

纵向扫描：以**第一个串**当基准，按列号（下标）走外层循环，内层把所有串的同一列拿出来对比。遇到需要"按位置逐个比"的字符串题，下标遍历比逐字符遍历更顺手。
</details>

<details><summary>💡 提示第 3 档·步骤点破（卡死 15 分钟才许开）</summary>

1. 先处理地基：数组为空直接交空串（本题约束保证非空，但写上这行是肌肉记忆）；
2. 以第一个串为基准，从第 0 列开始，一列一列往下查；
3. 每查一列：把其他所有串的这一列字母拿出来和基准串的这一列比；
4. 比的过程里两个"收工信号"任一出现就停——某个串太短没这一列了；或者有谁这一列的字母和基准不一样；
5. 停在哪一列，公共前缀就是前几列拼出的串——也就是基准串从头截到当前列；
6. 所有列都比完了还没触发收工，说明整个第一个串就是公共前缀（它是最短的公共串上限）。
</details>

<details><summary>📝 三句口述参考</summary>

1. 遍历什么：外层按第一个串的每一列（下标）走，内层遍历其余所有串。
2. 记录什么：当前比到第几列；一旦分叉，答案就是第一个串的前 i 个字符。
3. 怎么判断/返回：任一串在这列缺席、或这列字母与基准不同，立刻返回基准串 `[:i]`；全程没分叉则返回第一个串本身。空数组返回空串。
</details>

<details><summary>🔍 参考实现 + 逐行解析</summary>

**解法 A·纵向扫描版（主推）**

```python
class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:
        if not strs:
            return ""
        for i in range(len(strs[0])):
            ch = strs[0][i]
            for s in strs[1:]:
                if i >= len(s) or s[i] != ch:
                    return strs[0][:i]
        return strs[0]
```

- 第 3 行 `if not strs: return ""` —— 空数组直接交空串。本题约束保证非空，这行是防御性肌肉记忆——很多同类题约束里可没这句话，先写后删也比漏掉强。
- 第 4 行 `for i in range(len(strs[0])):` —— 外层走**列号**：从第 0 列比到基准串（第一个串）的最后一列。按列走正是"纵向"二字：拿第 i 列问所有串。
- 第 5 行 `ch = strs[0][i]` —— 把基准串这一列的字母先抄到手里，免得内层反复写下标。基准选第一个串是安全的：公共前缀的长度不可能超过任何一个串，自然也不会超过第一个。
- 第 6 行 `for s in strs[1:]:` —— 内层遍历其余串（从第 2 个开始，第一个自己和自己比是废动作）。
- 第 7 行 `if i >= len(s) or s[i] != ch: return strs[0][:i]` —— 一行压着两个收工信号：①这个串太短、第 i 列不存在（必须**先**判长度再取下标，反过来 Python 会在取 `s[i]` 时直接越界报错——`or` 是短路求值，左边成立就不看右边，顺序即保命）；②这个串第 i 列和基准字母对不上。任一信号出现，答案定格为基准串的前 i 个字符。用 `[:i]` 切片截断而不是另拼字符串——截的就是已经确认公共的那几列。反过来会怎样：写成 `return s[:i]` 大多数时候也对，但如果基准串比 s 长就截多了，认准基准串才稳。
- 第 10 行 `return strs[0]` —— 所有列比完都没分叉，说明第一个串整体就是公共前缀。缩进和 for 平齐：结论只能在全部循环走完后下，这行写进循环里第一列还没比完就提前交卷。
- 顺手记一个进阶写法：`for i, ch in enumerate(strs[0]):` 可以把第 4、5 行合成一行，enumerate 会同时给下标和字符——知道有这工具即可，先练清楚基础版。

**解法 B·横向两两缩版（知道有，理解用）**

- 思路：先拿第一个串当前缀，和第二个串比，比出来的公共部分当新前缀，再和第三个比……前缀只会越比越短，比到空串可以提前收工。和 A 是同一件事的两种走法：A 按列（所有串的第 i 列），B 按行（前两个串的公共部分滚雪球往右传）。面试先交 A，B 当备选谈资。
</details>

<details><summary>🪤 常见坑（按杀伤力排序）</summary>

1. **先取下标后判长度**：现象——`["flower","flo"]` 直接 `IndexError`。病因：短串没有第 i 列，先写 `s[i]` 后判 `len(s)` 程序就崩。修复：`i >= len(s)` 必须写在 `or` 的**左边**，靠短路求值先挡住越界。
2. **返回值截错对象或截错长度**：现象——`["flower","flow"]` 返回 `"flowe"`。病因：分叉时返回 `strs[0][:i+1]`（把分叉那列也算进去）或返回了别的串。修复：分叉发生在第 i 列，公共的只有前 i 列，认准 `strs[0][:i]`。
3. **全串公共时漏返回**：现象——`["ab","ab"]` 返回 `""`。病因：循环走完没写兜底 return，函数落回默认的 None。修复：循环外补 `return strs[0]`——能比完说明基准串整个都是公共前缀。
4. **忘空数组/空串边界**：现象——输入 `[]` 或 `[""]` 报错。病因：`strs[0]` 不存在或基准串为空。修复：开头 `if not strs` 防数组空；基准串为空时 `range(0)` 不进循环，自然落到 `return ""`，逻辑是通的，跑一遍确认即可。
</details>

<details><summary>🎯 对账五问（做完再展开）</summary>

1. 第一个卡点通常在"内层循环怎么表达'同一列'"——字符串要两个下标（第几个串、第几列），容易和数组题的一个下标搞混。画三行竖排的单词，手指沿列走一遍就清楚。
2. 最容易漏的动作：长度检查 `i >= len(s)` 必须在取 `s[i]` **之前**（短路顺序），以及循环外的兜底 return。
3. 为什么快：暴力是"两两比较所有串对"或"逐个字符重扫全表"，最坏 O(S·n)（S 是总字符数）里再叠常数；纵向扫描每个字符只被看一次，最坏 O(S)、空间 O(1)（不算返回的切片）。它快在**不重复劳动**：每列的结论当场生效，坏一列立刻停，不回头。
4. 信号词："公共前缀""开头相同""竖着比较"→ 纵向扫描。看到"逐位/逐列比较"就想：外层下标是位置，内层是候选们。
5. 变式：最长公共**后缀**？（每个串反转后求公共前缀再反转回来。）字符串数组里有空串混进来？（任一串为空，第 0 列就分叉，逻辑自动返回空串，不用特判。）
</details>

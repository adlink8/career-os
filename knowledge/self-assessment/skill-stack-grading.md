# 技能三级判定标准

> skill 读取 profile.yml 的 skills 字段时,按此标准判定等级,避免用户自评偏差。

## 三级定义

| 等级 | 判定标准(满足任意一条即可) | 典型证据 |
|------|---------------------------|---------|
| **熟练(proficient)** | 能独立完成 + 能教别人 + 遇到问题能排查 | 项目中使用过、有量化成果、能回答追问 |
| **掌握(familiar)** | 看得懂 + 能改 + 知道在哪查 | 课程项目、跟随教程做过、了解概念 |
| **学习中(learning)** | 知道是什么 + 在学 + 还没独立用过 | 在学课程、看书、未实践 |

## 自评偏差校准

用户常犯的偏差:
- **高估**:把"听过"当"掌握",把"做过教程"当"熟练"
- **低估**:有真实项目经验却只标"掌握"

skill 在评估时,应**结合 profile.yml 的 projects 字段交叉验证**:
- 如果某技能在 projects 里出现过且有量化成果 → 至少"熟练"
- 如果只在 skills 列表出现,projects 无佐证 → 最多"掌握"

## 对应 profile.yml 字段

```yaml
skills:
  proficient:   # 熟练
    - Linux
    - Python
  familiar:     # 掌握
    - Hadoop
  learning:     # 学习中
    - Kubernetes
```

## 升级触发条件

| 从 → 到 | 触发条件 |
|---------|---------|
| learning → familiar | 跟完一个完整教程/课程,能讲清概念 |
| familiar → proficient | **独立完成过一个真实项目**(非教程) |
| proficient → 精通(超出三级) | 有生产环境经验 + 处理过线上事故 |

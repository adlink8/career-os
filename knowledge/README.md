# 知识层索引

> Skill 引用这些知识文件来生成准确、有据可依的输出。
> 每个子目录有独立的 README.md 说明知识来源和更新方式。

## 目录

| 目录 | 对应步骤 | 知识来源 |
|------|---------|---------|
| self-assessment/ | 1. 自我定位 | MBTI, 霍兰德, 技能评估框架 |
| industry-reports/ | 2. 行业调研 | reportcamp, 艾瑞, 麦肯锡, 信通院 |
| roadmaps/ | 3. 学习路径 | developer-roadmap, roadmap.sh |
| jd-templates/ | 5. JD解读 | JD 解读模板与常见关键词库 |
| company-check/ | 6. 公司背调 | 企查查/天眼查, 背调清单 |
| resume-templates/ | 7. 简历定制 | STAR 模板, ATS 关键词 |
| assessment-banks/ | 9. 笔试测评 | 北森, 智鼎, SHL, 赛码 |
| interview-banks/ | 10-12. 面试 | CS-Notes, design-primer, 面经 |
| salary-data/ | 13. 谈薪 | 薪资行情数据 |
| onboarding/ | 15. 入职准备 | awesome-onboarding |
| survival/ | 16. 试用期生存 | First 90 Days, survival-guide |

## 使用方式

Skill 在运行时通过 `references/` 或直接读取对应 `knowledge/` 子目录获取知识。

```
# Skill 内部引用示例（SKILL.md 中）:
> 参考 knowledge/assessment-banks/北森题库.md 获取题型与策略
> 参考 knowledge/interview-banks/ 获取相关面试题
```

# 新人常见踩坑与应对

> 收录应届生职场第一年最常见的 20 个坑,每个含:场景 + 错误应对 + 正确应对。

## 一、沟通类

### 坑 1:不主动汇报,等领导问

- **场景:** 任务做完了,但没告诉领导
- **❌ 错误:** 默认领导会知道
- **✅ 正确:** 完成后主动说"X 任务已完成,结果是 Y"

### 坑 2:用微信/钉钉长语音说事

- **场景:** 遇到问题发 60 秒语音
- **❌ 错误:** 别人没空听/不方便听
- **✅ 正确:** 文字 + 必要时电话,长语音是大忌

### 坑 3:在群里公开反驳领导

- **场景:** 群里领导说了一个方案,你觉得不对
- **❌ 错误:** 群里直接怼
- **✅ 正确:** 私下找领导沟通,给台阶

### 坑 4:邮件抄送不全/乱抄送

- **场景:** 重要邮件漏抄领导
- **❌ 错误:** 信息断层,领导被 surprise
- **✅ 正确:** 想清楚"谁需要知道",按重要性抄送

## 二、任务类

### 坑 5:接任务不说 deadline

- **场景:** 领导说"做一下这个",你直接做
- **❌ 错误:** 默认什么时候交
- **✅ 正确:** 确认"什么时候要?"

### 坑 6:做不到 deadline 才说

- **场景:** 任务做不完,拖到最后才说
- **❌ 错误:** 让领导来不及调整
- **✅ 正确:** 发现风险立即说 + 给方案

### 坑 7:任务做完不验收就交

- **场景:** 写完代码/脚本直接交
- **❌ 错误:** 交一堆 bug
- **✅ 正确:** 自测 + 边界 case + 交叉 review

### 坑 8:同时接太多任务

- **场景:** 不会拒绝,什么都答应
- **❌ 错误:** 全做不好
- **✅ 正确:** 排优先级,与领导对齐

## 三、人际关系类

### 坑 9:不参与午饭/团建

- **场景:** 中午自己吃外卖,不去拼桌
- **❌ 错误:** 错过融入机会
- **✅ 正确:** 至少每周参与 2-3 次团队午餐

### 坑 10:背后说同事坏话

- **场景:** 私下吐槽某某不行
- **❌ 错误:** 必传到当事人耳朵
- **✅ 正确:** 有意见当面/向上反馈,不在背后议论

### 坑 11:跟老员工顶撞

- **场景:** 老员工方法老旧,你直接说"这不对"
- **❌ 错误:** 当面否定 = 树敌
- **✅ 正确:** 先理解为什么这么做,再私下提建议

### 坑 12:打听同事薪资

- **场景:** 悄悄问"你工资多少"
- **❌ 错误:** 职场大忌,可能违规
- **✅ 正确:** 永远不打听,通过行情自查

## 四、工作习惯类

### 坑 13:上班摸鱼被看到

- **场景:** 工作时间刷手机/看视频
- **❌ 错误:** 留下不上进印象
- **✅ 正确:** 想休息去茶水间/楼下

### 坑 14:下班秒走/卡点

- **场景:** 6:00 一到立刻消失
- **❌ 错误:** 显得不投入
- **✅ 正确:** 试用期多留 10-15 分钟,收尾当日事

### 坑 15:请假不合时宜

- **场景:** 关键节点请假/突然请假
- **❌ 错误:** 影响团队进度
- **✅ 正确:** 提前请,避开关键节点

## 五、运维专属坑(用户相关)

### 坑 16:直接改生产配置

- **场景:** 看到配置有问题,直接 vim 改
- **❌ 错误:** 出事没法回滚
- **✅ 正确:** 先备份 + 走变更流程

### 坑 17:用 root 干所有事

- **场景:** 嫌麻烦,什么都 sudo
- **❌ 错误:** 权限过大,事故风险高
- **✅ 正确:** 最小权限,需要时才提权

### 坑 18:不写文档

- **场景:** 解决了问题但不记录
- **❌ 错误:** 下次同样问题还要重新查
- **✅ 正确:** 每次排障都写工单/文档

## 六、职业发展类

### 坑 19:试用期就想跳槽

- **场景:** 觉得公司不行,刚入职就看机会
- **❌ 错误:** 简历难看(频繁跳槽)
- **✅ 正确:** 至少做满 1 年,积累真实经验

### 坑 20:只做被吩咐的事

- **场景:** 领导说啥做啥,不多不少
- **❌ 错误:** 显得没主动性
- **✅ 正确:** 做完后主动找下一个改进点

## 通用应对模板

遇到不确定的事:
```
1. 暂停(不要冲动反应)
2. 想清楚(影响范围?可逆吗?)
3. 询问(mentor/老员工/领导)
4. 执行(确认后再做)
5. 记录(留痕防扯皮)
```

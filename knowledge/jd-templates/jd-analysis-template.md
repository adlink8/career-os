# JD 结构化解读模板

> 当用户粘贴一段 JD 时,skill 按此模板拆解,输出:岗位画像 + 硬性要求 + 加分项 + 红旗 + 匹配度。

## 解读框架(5 个维度)

### 1. 岗位画像

```
岗位名:{}
公司规模:{推测或追问}
工作地点:{}
薪资范围:{是否与市场行情匹配}
经验要求:{应届/1-3年/3-5年}
学历要求:{}
```

### 2. 硬性要求(必须满足,否则过筛难)

```
必会技能:{列表}
必会工具:{列表}
必会认证:{如 HCIA/CCNA}
经验硬指标:{如"有百万级用户系统经验"}
```

### 3. 加分项(满足可提升竞争力)

```
优先技能:{列表}
优先项目经验:{}
证书:{}
```

### 4. 红旗(疑似坑位,需警惕)

- 薪资范围过宽(如 4-15k)= 实际偏低
- 要求"能加班""抗压能力强" = 996 嫌疑
- 要求"自带电脑""入职缴纳培训费" = **诈骗红旗**
- 岗位名与职责不符(招"运维"却要求"销售经验") = 挂羊头
- 要求加私人微信/QQ 面试 = 非正规流程

### 5. 匹配度分析(对照 profile.yml)

```
匹配度评分:
├── 硬性要求命中:{X/Y}
├── 加分项命中:{X/Y}
├── 差距:{列出用户缺的}
└── 建议:投 / 谨慎投 / 不投
```

## 输出格式

```
📋 JD 解读:{岗位名} @ {公司}

岗位画像:...
硬性要求(命中 X/Y):...
加分项(命中 X/Y):...
🚩 红旗:... 或 ✅ 未发现明显红旗
匹配度:{高/中/低}
建议:{投递/谨慎/不投} + 理由
```

## skill 调用提示

- 解读时必须读 `config/profile.yml` 做匹配
- 红旗项参考 `knowledge/company-check/` 的风险库

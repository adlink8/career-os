# 网络运维 / 系统集成学习路线(用户兴趣线)

> 来源:[roadmap.sh/computer-network](https://roadmap.sh/computer-network) + 华为/思科认证体系。

## 路线图

```
阶段 1: 网络基础(用户部分已掌握)
├── ✅ VLAN / 路由 / 交换(用户有竞赛经验)
├── ✅ 抓包(Wireshark,用户有排障案例)
├── 🟡 TCP/IP 协议栈深入
└── 🔴 子网划分 / CIDR
          ↓
阶段 2: 网络设备
├── 🔴 华为 VRP / 思科 IOS 命令
├── 🔴 防火墙配置
├── 🔴 VPN(IPSec / SSL VPN)
└── 🔴 无线网络(WLAN)
          ↓
阶段 3: 认证体系(加分项)
├── 🔴 HCIA(华为初级,国内中小厂认可)
├── 🔴 CCNA(思科初级,外企认可)
└── 🔴 HCIP / CCNP(中级,进阶)
          ↓
阶段 4: 系统集成
├── 🔴 综合布线
├── 🔴 机房建设
├── 🔴 网络安全(等保 / IDS / IPS)
└── 🔴 桌面运维(外企 IT Support 常见)
```

## 用户优势(来自 profile.yml)

- **江苏省物联网技能大赛** → 局域网组网 + VLAN 故障排查,直接对口
- **抓包定位 trunk 端口问题** → 真实排障案例,面试故事

## 优先补齐

1. **HCIA 知识体系**(即使不考证,内容也是面试常问)
2. **防火墙基础概念**(中小厂运维必问)
3. **VPN 配置**(外企/远程办公场景常见)

## 适用岗位

- 网络运维工程师(中小公司)
- 系统集成工程师
- 外企 IT Support(配合英语)

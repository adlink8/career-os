# IoT 平台运维学习路线(用户差异化方向)

> 来源:roadmap.sh 无专门 IoT 路线,综合 AWS IoT 文档 + 社区经验整理。

## 路线图

```
阶段 1: 嵌入式通信(用户大部分已掌握)
├── ✅ MQTT 协议(用户熟练)
├── ✅ ESP32/网关(用户有项目)
├── 🔴 CoAP / LoRa / NB-IoT(扩展)
└── 🔴 边缘计算框架
          ↓
阶段 2: IoT 云平台
├── ✅ AWS IoT Core(用户掌握)
├── 🔴 阿里云 IoT 平台
├── 🔴 腾讯云 IoT Explorer
└── 🔴 华为 IoT 设备管理
          ↓
阶段 3: 数据管道
├── ✅ Kafka(用户掌握)
├── 🔴 时序数据库(InfluxDB / TimescaleDB)
├── 🔴 Flink 实时处理(用户有基础)
└── 🔴 数据可视化(Grafana)
          ↓
阶段 4: 设备运维
├── 🔴 OTA 升级管理
├── 🔴 设备影子(Device Shadow)
├── 🔴 规则引擎
└── 🔴 海量设备监控
```

## 用户优势(来自 profile.yml)

- **江苏省物联网技能大赛经验** → 组网 + 故障排查,对口
- **AWS IoT 管道项目** → 完整链路经验,直接相关
- **keepalive 故障排查案例** → 真实问题解决经验,面试加分

## 优先补齐

1. **阿里云 IoT 平台**(国内中小厂主流,AWS 在国内渗透低)
2. **时序数据库**(IoT 数据标配)
3. **OTA + 设备影子概念**(面试常问)

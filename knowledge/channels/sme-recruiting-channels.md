> 渠道清单（第一~五节）仍然有效，但**对成功率的预期必须按第六节下调**。

## 四、不要碰的

- 任何要交钱的内推 / 实习 / 培训
- 标题含「高薪急招」「日结」「无经验月入过万」
- 招聘主体与公司名称不一致（多为外包/中介）
- 薪资明显虚高：常州应届技术支持 >10k 需警惕

# 六、交叉验证与结论修正（2026-09-06）

对用户质疑「真的假的」做的一次外部交叉验证。**结果部分推翻了本文件原版的乐观判断。**

## 6.1 逐条验证

### ✅ 成立：「中小厂不走校招通道」

| 证据 | 来源 | 强度 |
|------|------|------|
| 中小企业「计划招聘正式员工中走校招的比例」一季度 7.6% → 二季度 7.8%，未恢复至去年同期 | 中国劳动和社会保障科学研究院 https://www.calss.net.cn/p1/zjsd/20240402/38671.html | **官方权威，强** |
| 高校对进校企业有标准要求，"一些民营企业很难满足"；教育部门对企业进校园招聘有时限 | 同上 | **官方权威，强** |
| 100 人以下中小企业收入占比**首次突破 50%**，累计服务企业超 2000 万家，付费企业 680 万 | BOSS 直聘 2025 财报（新浪财经/腾讯新闻转载） | **上市公司财报，强** |

→ 机制清楚了：中小厂不是"有校招但难找"，是**它们的应届招聘根本不挂在"校招"名下**，走日常招聘 + 平台直聊。所以按"校招"关键词搜索必然扑空。

### ✅ 成立：「中小厂是吸纳毕业生的主体」

| 证据 | 来源 | 强度 |
|------|------|------|
| 某高校 2025 届 **85.25% 流向中小企业**；单位规模 101-200 人 28.34%、50 人以下 26.34%、51-100 人 26.22% | 浙江省高校毕业生就业管理系统（PDF 原件） | **官方系统数据，强** |
| 注册资本 [1000万,1亿) 32.1% + [1亿,10亿) 22.7%，中型企业是大学生招聘主力 | 猎聘大数据《2025届大学生就业供需洞察报告》 | 中 |
| 民企贡献 80% 城镇就业、90% 新增就业，每年约 60% 高校毕业生到民企就业 | 山西省工商联（中华工商时报） | 中（官方表述但为动员口径） |

### ❌ **不成立：「中小厂容易进、没人抢」——这是原版最大的错误**

| 反证 | 来源 | 强度 |
|------|------|------|
| **仅 23% 的中型企业维持往届应届生招聘规模**；不少中小制造/商贸/互联网企业直接砍掉基础新人岗位，预算转向社招熟手 | 转述自前程无忧《2026 年一季度招聘行情报告》 | 中（自媒体转述，原始报告未直接获取） |
| 要求 **3 年以上经验的岗位占比超七成**，面向零基础应届生的入门岗持续缩减 | 转述自脉脉 2026 春招洞察 | 中（转述） |
| 2026 春招平均 1 个岗位收 17.2 份简历；应届生平均投 **150-200 份换 1 次面试**；整体 offer 率**不足 8%** | 转述自智联招聘数据，多来源一致 | 中（转述，但多源一致） |
| 小微企业主自述："小公司一个萝卜一个坑，招应届生上手慢，不如直接招熟手" | HRTechChina / 新浪新闻调查 | 中（个案，非统计） |

→ **中小厂不是蓝海。** 它们的应届入口在收缩，且门槛上移到"能用就行"。你不是跟同龄人抢，是跟有 1-3 年经验的人抢同一批"经验不限"岗。

### ⚠️ 需要打折：「本地招聘会是小微厂的富集地」

反证：2026-10-09 武进巡回招聘会·常州大学站已确认的参展单位规模是 **100-499 人 / 500-999 人 ×3 / 1000-9999 人**，行业为金属容器、光伏新材料、薄膜、高分子材料 —— **是中型和大型制造企业，不是 10-50 人的 IoT 小公司**，且未必有 IT 技术支持岗。

叠加官方文件"高校对进校企业有标准要求，一些民营企业很难满足" → **小微厂进不了校门**。

→ 招聘会值得去，但预期要调成「接触本地中型制造企业」，不是「遇到一堆 IoT 小作坊」。

### ⚠️ 存疑：「中小厂 6-8k 起薪」——可能偏高

- 转述数据：全国中小民企应届生平均起薪 3500-5500 元（口径存疑）
- 麦可思（转述）：2026 届应届生全国平均签约月薪 **5800 元**，较三年前下降 9%
- 但上述含大量行政/文科岗。常州 IoT/技术支持岗应高于全国平均。

→ **报价口径下调为：中小厂报 5.5-7k，底线 5k。** 原来"报 7-8k 底线 6k"偏乐观。

## 6.2 一个重要的反向发现（对用户有利）

**2026 春招出现学历倒挂：专科 offer 率 56% > 普通本科 45% > 硕博 40%。**

企业方原话（转述）："宁花 5000 招本科生，也不花 7000 招研究生"——中小微要的是**薪资预期不高、来了就能干活**的人。

→ **专升本在这条赛道上不是主要障碍**，甚至相对硕士占优。这条**支持**原判断。

另：新一代信息技术应届职位数占比 46.4%（行业第一），智能制造人才缺口 450 万。

## 6.3 修正后的结论

| 原判断 | 修正后 |
|--------|--------|
| 中小厂是蓝海，容易进 | ❌ **中小厂是就业主体（85% 毕业生去那儿），但入口在收缩、门槛在上移** |
| 中小厂不卡学历 | ✅ 成立，且有学历倒挂数据支撑 |
| 中小厂不强制实习 | ⚠️ 理论成立，但实际要求"来了就能干活"，等价于要求有可证明的动手能力 |
| 中小厂 6-8k | ⚠️ 下调至 **5.5-7k，底线 5k** |
| 渠道：BOSS直聘 + 本地 + 直连 | ✅ **渠道判断不变，且被 BOSS 财报（100人以下企业收入占比>50%）证实** |

## 6.4 对用户策略的实际影响

1. **渠道方向没错，成功率预期要降。** 不是"投 30 家中小厂必中"，是"投 30 家可能拿 1-2 个面试"。
2. **中小厂要"来了就能干活" → 当场能演示 > 投多少家。** AWS IoT 管道、MQTT、Docker、GitHub 1559 commits 必须能现场打开讲，这比海投重要一个数量级。
3. **别只盯小微。** 本地中型制造企业（招聘会上那种 100-999 人的）也要投，它们更可能有 HC。
4. **大厂的技术支持/FAE 岗不能放弃。** 中小厂收缩应届 + 大厂 FAE 岗存在，两条线并行才是合理配置。

# 七、库内实证：官网校招通道的岗位结构（2026-09-06）

用户提问「所以官网的校招基本都是大厂」→ 用 `platform_recruitment_leads` 做实证，结论**成立，且比提问更极端**。

## 7.1 官网校招通道 = 大厂，且 = 算法研发岗

`platform='官网校招'` 共 **99 条线索 / 46 家去重公司**。公司全为上市、独角兽或明星科创（科大讯飞、MiniMax、智元、宇树、追觅、石头、Momenta、第四范式、极视角、网易有道、浩鲸、朗新、恒生、中兴、东软、海康、汇川、优博讯、研华、移远…）。**零中小厂。**

岗位类型分布（同一条可命中多类）：

| 类型 | 条数 |
|------|------|
| 开发 / 工程 | 98 |
| **算法 / 研发 / 模型** | **52** |
| 硬件 / 嵌入式 | 18 |
| **技术支持 / 交付 / 运维 / 实施** | **11（11%）** |
| 产品 / 设计 / 职能 | 3 |

**关键结论：官网校招不只是"大厂"，还主要是"算法研发岗"。目标岗位（技术支持/FAE/运维）在该通道里只占 11%，且这 11 条所属公司依然全是大厂/上市。**

那 11 条具体是：浩鲸云交付与技术支持、招银 DevOps/SRE、中兴 IT 运维与技术支持、东软系统工程师与实施运维、海康 FAE、交行金科、汇川 FAE、优博讯 IoT FAE、研华 IoT FAE、移远 FAE、无锡中科微至技术支持。

# 八、机制解释：为什么只有大厂有官网校招通道（2026-09-07）

## 8.1 一句话结论

**不是"中小厂不能做校招"，是"校招是一套固定成本很高、只有招聘量足够大才摊得平的工业装置"。**
中小厂不是被大厂挤出去的，是被成本结构和准入门槛双重过滤掉的。

## 8.2 五层过滤机制

### 第 1 层：高校准入制度（硬约束，最狠）

985/211/双一流及大部分本科院校对进校企业设资质门槛。实例（闽江学院就业网公开招聘会规定）：

| 准入条件 | 卡掉谁 |
|----------|--------|
| 注册资金 ≥ 1000 万 **或** 年均营收 ≥ 500 万 | 大量初创/小微 |
| 单位员工规模 ≥ 100 人 | 50 人以下公司（占毕业生流向 26%）直接出局 |
| 所有岗位最低月薪（不含绩效）≥ 4500 元 | 低薪岗 |
| 中国 500 强 / 世界 500 强（优先项） | — |

其他院校口径：注册资金 ≥ 100 万、薪资 ≥ 3500 元/月、须提供营业执照 + 招聘公函 + 招聘人员身份证明、3 个工作日审核。

**这是制度性过滤，不是企业自愿选择。** 与中国劳动和社会保障科学研究院的表述一致："一些民营企业很难满足这些要求"。

→ 直接解释了中国劳动保障科学研究院那个数字：中小企业计划招聘中走校招的只有 **7.6%~7.8%**。

### 第 2 层：固定成本结构（经济账）

校招的成本大头与招多少人**几乎无关**：

- 官网校招门户 / ATS 系统（年费）
- 雇主品牌（宣讲会、物料、校园大使、线上推广）
- 校招团队人力（专职校招 HR + 业务面试官时间）
- 集中入职的 Onboarding 与管培体系
- 三方协议、违约处理、集中办理手续

**摊薄公式**：大厂年招 500+ 应届 → 单人成本几百元；小厂年招 2 个 → 单人成本上万。
招聘规模是分母，小厂分母太小，校招这条路在数学上就不成立。

### 第 3 层：招聘节奏不匹配（最容易被忽略）

| | 大厂 | 中小厂 |
|---|---|---|
| 性质 | **期货**——提前 9-12 个月锁定 HC，次年集中入职 | **现货**——缺人了马上要，最好下周能上班 |
| 前提 | 有年度编制、有预算规划、敢提前承诺 | 业务波动大，不敢提前一年承诺 HC |
| 违约承受 | 高 | 低 |

小厂一个萝卜一个坑，没法等一年。

### 第 4 层：培养能力不对称

校招进来的是白纸，需要导师、培训、试错空间。大厂有管培体系和人才梯队；小厂"招来就得干活"，养不起"半年后才产出"的人。

→ 这直接解释了第六章那条数据：**要求 3 年以上经验的岗占比超七成，零基础应届入门岗持续缩减**（脉脉 2026 春招，中等证据）。
中小厂不是不招新人，是**把校招做成了社招的形状**。

### 第 5 层：风险不对称

应届生违约率与首年流失率高。大厂流失 10 个还剩 990 个，且有雇主品牌兜底 offer 接受率；小厂招 2 个走 1 个就是 50% 损失。

## 8.3 为什么 BOSS 直聘正好反向匹配中小厂

| 中小厂的需求 | BOSS 直聘的形态 |
|---|---|
| 没有固定预算养校招团队 | 零固定成本，按效果付费，不发岗位不花钱 |
| 现货招聘，明天就要人 | 今天发、明天聊、下周上班 |
| 没有 HR 团队筛几千份简历 | 直聊替代 ATS，老板自己聊 10 分钟判断 |
| 过不了高校资质审核 | 平台无规模/注册资金门槛 |
| 招 1-2 个人，不需要批量 | 单岗位发布即可，无最小起批量 |

**BOSS 直聘 2025 财报：100 人以下中小企业收入占比首次突破 50%，累计服务企业超 2000 万家。**（强证据）
这不是巧合，是产品形态与成本结构正好匹配。

## 8.4 最重要的推论（对求职姿势的影响）

**中小厂不是"不做校招"，是"把校招做成了社招的形状"。**

| 你以为的校招 | 中小厂的真实形态 |
|---|---|
| 岗位名叫「2027 届校园招聘」 | 岗位名叫「技术支持工程师」 |
| 有明确截止日期（9-11 月） | 全年开放，无截止日期 |
| 在官网校招页 / 学校就业网 | 在 BOSS 直聘 / 智联 / 本地人才网 |
| 投递走 ATS 网申 | 直聊 / 打电话 / 上门 |
| 流程：测评 → 群面 → 一面 → 二面 | 流程：老板聊一次就定 |

→ **所以你按"校招"关键词去搜，永远搜不到它们。搜不到 ≠ 不存在。**

## 8.5 库内实证（2026-09-06 跑数）

`platform_recruitment_leads` 官网校招 99 条线索、46 家去重公司：**零中小厂**。
全为上市、独角兽或明星科创（科大讯飞、MiniMax、智元、宇树、追觅、Momenta、第四范式、网易有道、浩鲸、朗新、恒生、中兴、东软、海康、汇川、优博讯、研华、移远……）。

**且岗位结构进一步偏移**：开发/工程 98 条、算法/研发/模型 52 条、硬件/嵌入式 18 条、**技术支持/交付/运维/实施仅 11 条（11%）**。

→ 官网校招通道对你是**双重堵死**：中小厂没有官网校招，大厂校招里技术支持岗又只占 11%。

## 8.6 数据可靠性

- **强证据**：闽江学院/河南科技学院/湖南商务职院等高校就业网公开的进校资质规定（制度原文）、BOSS 直聘 2025 财报、库内 99 条线索实证、中国劳动和社会保障科学研究院。
- **中等/需谨慎**：英文来源的 cost-per-hire（校招约 $6,275 vs 全渠道约 $4,700，Handshake/Unstop）为美国市场口径，**仅用于说明"校招单人成本高于平均"这一方向性结论，不直接套用到中国**。
- **逻辑推演（非实测）**：第 2/3/4/5 层的机制分析基于成本结构与制度约束推理，方向可信，具体数值未实测。

# 九、流程长度的决定因素（2026-09-07）

## 9.1 纠正一个常见误解

> 误解：「测评 + 一面二面三面 = 大厂专属，因为大厂投的人多」

**方向对，但分界线画错了位置。**

准确表述：**流程长度由「单个岗位的候选人供给量 ÷ 处理该供给的能力」决定，而不是由公司规模决定。**

- 大厂之所以流程长，是因为它走**公开网申入口**，一个岗几千人投，必须用标准化工具（测评、ATS、结构化面试）把人工成本压下去。
- 中小厂流程短，是因为它走**按需直聊入口**，池子小，不需要机器初筛。

**所以真正的分界线是入口类型，不是公司规模。**

## 9.2 反证：不是大厂，但流程最长

国企 / 央企 / 银行 / 事业单位的流程**比互联网大厂更长**：

网申 → 统一笔试（行测+专业）→ 一面 → 二面 → 体检 → 政审/背调 → 公示

典型 5-6 关，周期 1-3 个月。它们很多不是"大厂"，但供给量极大且决策链长。

**结论：把"流程长"归因于"公司大"会误判。** 决定因素依次是：
1. 是否公开网申（供给量）
2. 决策链长度（国企 > 民企）
3. 招错人的代价（一个萝卜一个坑的小厂反而更谨慎，但它用"老板亲自面"代替"多轮"）

## 9.3 测评工具的客户结构（重要纠偏）

**测评不是大厂自建的，是买来的 SaaS。** 北森、智鼎、SHL、赛码、牛客都对外售卖，中型企业也用。

北森公开客户清单（自媒体汇总，多源一致）：
- 互联网：字节、京东、拼多多、携程、阿里、百度、快手、vivo、海康、中兴、科大讯飞、小米、贝壳
- **实体/消费（很多是中型或非互联网）**：广州地铁、广州铁路局、传音控股、基恩士、广联达、中国建筑、中国交建、名创优品、良品铺子、康师傅、瑞幸、蔚来、蓝月亮、蒙牛、伊利、金风科技、安克创新、欣旺达、三一、奥克斯、九阳、格力、美的、追觅、泡泡玛特、蜜雪冰城、立白、中科曙光
- 金融：浦发、杭州银行、民生、广发、兴业、申万宏源、中信证券、国泰君安、各基金保险

智鼎客户：腾讯、中国电信、华润置地、浪潮、**国网南瑞集团**、中国商飞、阿斯利康、阳光电源、联影集团、工行/中行/邮储各省分行春招。

→ **国企央企银行是测评的重度用户**（智鼎大量案例是银行分行校招与人才盘点）。

### 但真正的断点在 100 人以下

100 人以下小微通常**没有专职 HR**，更不会采购测评 SaaS。它们用"老板聊一次"替代整个流程。

> **所以：100-999 人中型企业 ≠ 无测评。100 人以下才是。**

## 9.4 校招笔试的淘汰强度

多源一致（自媒体，中等证据）：**校招笔试淘汰率 70%~80%**。

→ 如果走公开网申路线且完全不刷题，笔试环节大概率直接出局。**但这是"走这条路才需要付的成本"，不是"找工作必须付的成本"。**

| 大厂校招官网的**技术支持/FAE/实施/交付岗** | **保留，限量投 8-10 个** | 专业岗，全国投向该赛道的应届生池子远小于算法/研发；且薪资是全库天花板（新大陆 7.5-11k、研华 8-12k、优博讯 8-13k、海康 10-15k、汇川 12-18k、基恩士年薪 18-25w） |
| 九号（常州本地大厂，46 条） | **挑 3-5 个投** | 本地雇主 + 已有 2 条在流程中 + 本地院校偏好 |
| **本地小池子网申**（学校就业网、常州人才网、就在江苏） | **保留，高优先级** | 形式上是网申，但池子只有本校/本市，流程短，是中小厂主场 |
| BOSS 直聘 / 智联 / 内推 / 电话 / 上门 | **主力** | 无测评、无机器初筛 |

**一句话：放弃的是"全国性公开校招入口"，不是"网申这种形式"。**

# 十、BOSS / 智联采集方案评估（2026-09-07）

> 起因：用户问「有没有项目能从 BOSS 和智联搜集岗位和 JD」。结论是**能做，但不该优先做**。见 10.4。

## 10.1 项目现状：采集管道从未覆盖中小厂

`jobs.source_plugin` 分布：`campus-crawler-agent` 95、`ninebot-live-moka` 72、`aispeech-zhiye-campus` 35、NULL 58。

**三个采集器全部面向企业校招门户，无一涉及 BOSS / 智联 / 本地平台。** 与 9.6 的 `application_url` 域名实证互相印证。

## 10.2 开源方案与技术可行性

### BOSS 直聘

反爬机制（2026 现状）：
- `__zp_stoken__` 动态加密，算法为 **LCG 随机数 + 魔改 SHA1 + CRC + UA 哈希 + XOR 混淆**，有效期约 15 分钟
- 服务器下发 `code=37`（token 失效）后需用 `seed/ts/name` 重算；`code=32` 为账号风控
- 连续 5 次请求间隔 < 800ms 大概率触发滑块；建议翻页间隔 15-30 秒
- 前端薪资为**字体反爬**（自定义字体映射，HTML 里是乱码）

方案排序（多源一致）：

| 方案 | 稳定性 | 说明 |
|---|---|---|
| **iv8 本地执行官方 JS** | ★★★★★ | `pip install iv8`，直接加载官方 JS 在沙箱算 token，**算法更新自动适配，无需逆向维护** |
| **Chrome CDP / DrissionPage 复用真实登录态** | ★★★★☆ | 扫码登录一次，Cookie 落盘复用；绕过字体反爬；最常见也最稳 |
| `kabi-boss-cli`（纯 HTTP） | ★★★☆☆ | 最快，但 `zp_stoken` 常缺失，登录坑多 |
| 纯 Python 复现 token 算法 | ★★☆☆☆ | 算法一改就失效，需持续维护 |

可参考项目：
- `luo178/boss-zhipin-scraper` —— Chrome CDP 复用登录态，绕过字体反爬，输出明文薪资 JSON/CSV，含薪资分布与技能词频。**2026-07 仍在更新**。
- `bcefghj/JobOS` —— AI 求职操作系统（采集→10 维评分→定制简历→面试资料→投递指南），与本项目 Career OS 高度重合，其 DrissionPage 采集模块可直接借鉴。

### 智联招聘

**明显比 BOSS 简单：**
- PC 端页面薪资常为「面议/年薪制」等非数字，**移动端 H5 API 返回标准化数值**
- 直接调 `https://fe-api.zhaopin.com/c/i/sou?start=0&pageSize=90&cityId=530&kw=<关键词>`
- 需 cityId 映射表（如北京=530），避免中文编码问题

## 10.3 风险（必须知道）

- **违反平台用户协议**，账号可能被风控、限流或封禁（BOSS 的 `code=32` 就是账号级风控）
- 低频、个人用途、不传播、不商用 → 实际法律风险低；但**账号被封是真风险**，且 BOSS 账号关联手机号
- **维护成本**：BOSS 改接口即失效，纯 Python 方案每次都要重新逆向
- 抓取数据**不得公开分发或商用**

## 10.4 判断：不该优先做

**当前瓶颈不是数据不足，是转化率为零。**

| 已有 | 已动用 |
|---|---|
| 库内待投递岗位 138 | 6 |
| 中小厂名录 214 家 | 0 |

再抓 1000 个岗位不会提高 offer 概率。**抓来的数据是死数据，打出去的电话才是活数据。**

### 如果真要爬，唯一值得做的用法：「公司反查」，不是「岗位搜索」

| 用法 | 价值 |
|---|---|
| 岗位搜索（搜「技术支持 常州」） | 低：数据重复、噪音大、与已有 138 条高度重叠 |
| **公司反查（拿 214 家公司名去 BOSS 逐个查在不在招）** | **高：精准对接已有名录，把「待核实」变成「在招/不在招」，且手工做很累** |

### 建议顺序

1. **先手工跑通第一批 20 家**（`data/sme-outreach-batch1.md`），验证 BOSS 上常州中小厂的命中率。
2. 命中率 > 30% → 再考虑自动化；命中率 < 10% → 说明名录本身是垃圾，爬了也白爬。
3. 若自动化，从**智联 H5 API** 起步（最简单、无需登录态），BOSS 用 DrissionPage + 已登录 Cookie。

# 简历排版方案库(4 套)

> **适用对象:** `data/cv/cv-*.md` 各版本简历(内容 5 模块:求职意向/教育/技能/项目×4/证书)。
> **硬约束来源:** `ats-optimization.md` —— 凡走招聘平台/官网投递的版本,必须单栏、标准字体、无表格、无文本框。
> **使用方式:** 选定方案 → 按参数在 Word/WPS 或 Pandoc 排版 → 导出 PDF → 命名 `姓名_岗位_简历.pdf`。

---

## 方案 A · 经典单栏 ATS 版(默认首选)

**适用:** 官网投递、Boss/实习僧等走 ATS 的平台;对应 `cv-ops.md`、`cv-network.md`。

| 参数 | 值 |
|------|-----|
| 纸张/页边距 | A4,上下 2.0cm,左右 2.2cm |
| 中文字体 | 微软雅黑(备选:思源黑体) |
| 西文/数字 | Arial(与中文混排时技术栈名称统一 Arial) |
| 姓名 | 20pt 加粗,居左 |
| 意向+联系方式 | 10.5pt,姓名下方两行,行内用 `|` 分隔 |
| 模块标题 | 12pt 加粗 + 整行通栏细分隔线(0.75pt,黑色) |
| 正文 | 10.5pt,行距固定值 18-20pt |
| 项目标题 | 11pt 加粗,年份右对齐同行 |
| 配色 | 纯黑白灰,零强调色 |
| 页数 | 1 页 |

**模块顺序:** 意向 → 教育 → 技能 → 项目经历 → 证书与竞赛。

**要点:** 模块标题用"细分隔线"而不是色块,ATS 解析最稳;技能三级(熟练/掌握/学习中)原样保留,是差异化加分项。

---

## 方案 B · 技术标签项目版(投技术岗)

**适用:** 投 IoT/AI Infra/云平台类 JD,对应 `cv-iot.md`、`cv-ai-infra.md`;HR 和技术面试官 6 秒扫读场景。

在方案 A 基础上做三处改动:

1. **项目标题下加一行技术标签**(10pt,灰色 #595959,Arial):
   ```
   AWS IoT 数据管道(2024)
   ESP32 · MQTT · Docker · Ubuntu · AWS IoT Core · S3
   - 搭建 ESP32 设备数据采集与 MQTT 上报的完整链路
   ...
   ```
   标签行让 JD 关键词在视觉上"跳出来",同时不破坏 ATS 文本解析(纯文本行,不是文本框)。
2. **量化成果前置:** 每个项目把含数字的 bullet 提到第一条(如"在线率 85%→99%"),扫读时先看到结果。
3. **模块标题可加单色强调:** 若目标公司允许设计感,标题用深蓝 #1F3864(黑白打印仍清晰);不确定就保持纯黑。

**模块顺序:** 意向 → 技能 → 项目经历 → 教育 → 证书(技能前置,技术岗先看栈)。

---

## 方案 C · 紧凑海投一页版

**适用:** 招聘平台附件、微信群直发、快速沟通;对应 `cv-compact.md`。

| 参数 | 值 |
|------|-----|
| 页边距 | 上下 1.5cm,左右 1.8cm |
| 姓名 | 18pt 加粗,意向与联系方式压缩到同一行区块 |
| 模块标题 | 11pt 加粗,去掉分隔线改用段前 6pt 间距 |
| 正文 | 10pt,行距固定值 16pt |
| 项目 | 只保留 3 个最强项目,每个项目压缩到 2-3 条 bullet |
| 教育+证书 | 合并为一个模块"教育与证书",各占一行 |

**要点:** 这套是"省空间优先",牺牲呼吸感换信息密度;只用于明确一页要求的场景,正式投递仍用 A/B。

---

## 方案 D · 面谈携带人读版(不进 ATS)

**适用:** 面试现场纸质版、内推人微信直发、线下双选会。**禁止上传任何招聘平台。**

在方案 B 基础上放开两条 ATS 禁令:

- **左侧窄栏(约 30% 宽):** 放联系方式、技能三级、证书;右侧主栏放项目经历和教育。左栏用浅灰底 #F2F2F2 或细分隔线区分。
- **允许一个强调色:** 深蓝 #1F3864 用于姓名和模块标题,打印店彩打/黑白打印均可读。

**警告:** 双栏 + 色块 = ATS 解析错乱高风险。此版只在"确定是人在看"的通道使用;同一场合若要既过机筛又给人看,永远优先交方案 A/B 的 PDF。

## 选型速查

| 场景 | 用哪套 | 内容版本 |
|------|--------|----------|
| 官网/平台投运维、技术支持 | A | `cv-ops.md` / `cv-network.md` |
| 官网/平台投 IoT、AI Infra | B | `cv-iot.md` / `cv-ai-infra.md` |
| 海投、平台附件、快速沟通 | C | `cv-compact.md` |
| 面试纸质版、内推直发 | D | 按岗位选内容版本 |

## 通用检查(导出 PDF 前)

1. 全文单栏(A/B/C),无表格、无文本框、无页眉页脚关键信息。
2. 手机号/邮箱独立可选取(导出后尝试用鼠标选中,选不中 = 图片化,重做)。
3. 日期格式全文统一(如 `2024.06`,不要混用 `2024-06`)。
4. 文件名 `姓名_岗位_简历.pdf`。
5. 一页放不下时:先砍项目 bullet(每个项目最少保留 1 条量化成果),再动字号(下限 10pt),最后动页边距(下限 1.5cm)。

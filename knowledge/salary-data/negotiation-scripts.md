# 谈薪话术与策略

> 应届生谈薪的核心:**有底线 + 可商量 + 不卑不亢**。
> 谈薪能力是职场核心技能,第一份工作的起薪会影响后续涨幅基数。

## 谈薪黄金原则

### 1. 不要先开价

- HR 问"你的期望薪资?"→ **不要直接报数字**
- 反问:"贵司这个岗位的薪资区间是多少?"
- 让 HR 先说,你再根据区间回应

### 2. 给区间,不给单点

- 报"6-8k"而不是"6k"
- 区间下限 = 你的底线,上限 = 理想
- 留谈判空间

### 3. 算总包,不算月薪

```
不要只看月薪,要看:
- 月薪 × 月数
- 公积金比例(隐形收入/损失)
- 补贴
- 年终奖
- 期权(谨慎)
```

### 4. 拿到 offer 后再谈

- 面试中谈薪 = 姿势弱(还没被录取)
- offer 阶段谈薪 = 姿势强(已被录取,有筹码)

## 分场景话术

### 场景 1:HR 电话问期望(面试中)

**❌ 错误回答:**
```
HR:你的期望薪资?
你:6k。
```

**✅ 正确回答:**
```
HR:你的期望薪资?
你:薪资我会综合考虑岗位内容、团队和成长空间。
   我了解到 {城市} {岗位} 应届大致是 X-Yk,
   我希望在这个区间内,具体想了解贵司的薪资结构。
HR:我们这个岗位是 X-Y。
你:明白了,了解贵司的薪资构成后我再综合判断。
```

### 场景 2:Offer 阶段谈薪(筹码最强)

**话术:**
```
非常感谢 offer。我认真考虑了岗位内容,非常期待加入。
关于薪资,我了解到市场同岗位应届大概在 X-Yk,
目前 offer 给的是 Xk,能否往 Yk 靠拢?
我有 {竞品 offer/项目经验/竞赛},希望能体现。
```

**关键:**
- 先表达"想加入"(不威胁)
- 再用"市场数据"支撑
- 最后用"自身筹码"加码

### 场景 3:HR 说"应届都这个价"

**反问话术:**
```
我理解应届有统一标准。能否介绍一下:
- 试用期多久?试用期工资比例?
- 转正后调薪机制?
- 公积金按什么基数交?
```

**目的:** 把"月薪"拆成多个维度,找到加价空间。

### 场景 4:多方 offer 比价

**话术(对意向公司):**
```
我目前收到另一家 offer,薪资是 Xk。
但我更倾向贵司,因为 {业务/团队/成长}。
如果薪资能匹配,我直接签贵司。
```

**注意:** 必须是真的有竞品 offer,不要虚张声势。

## 谈薪心理战

### HR 常用套路

| HR 话术 | 真实意图 | 你的应对 |
|---------|---------|---------|
| "应届生都这个价" | 压价 | 问具体薪资构成 |
| "我们给成长空间" | 转移注意力 | "成长和薪资不矛盾" |
| "你还没经验不值这个价" | 打压自信 | "我的项目经验能快速上手" |
| "offer 有时效,尽快定" | 制造紧迫感 | "我需要 X 天综合考虑" |
| "别的应届都接受了" | 从众压力 | "每个人的情况不同" |

### 你的心态

- **不卑:** 你有技能 + 项目,是去创造价值的
- **不亢:** 应届确实没经验,不要漫天要价
- **有备:** 提前查好市场行情(本目录 + 实时搜索)
- **有底:** 知道自己的最低接受线(profile.yml: 不低于 4k)

## 谈薪红线

### ❌ 绝对不要

- "我爸妈说至少要 Xk"
- "我同学拿了 Xk"(攀比)
- "低于 Xk 我就不去了"(威胁,除非真有备选)
- 一次性报死数字(不留余地)

### ✅ 应该

- 用市场数据说话(中性)
- 强调自身价值(项目/技能/竞赛)
- 留余地("可以谈""综合考虑")
- 感谢 offer 再谈(礼貌但坚定)

## 谈判失败怎么办

如果谈不动:
1. **接受 + 关注成长:** 第一年学东西,第二年跳槽涨薪
2. **争取非现金:** 公积金基数/调薪承诺/培训预算
3. **明确试用期:** 缩短试用期或提高试用期工资比例

- 输出话术时,根据用户具体场景(面试中/offer 阶段)定制
- 提醒用户:谈薪是双向选择,不要怕谈

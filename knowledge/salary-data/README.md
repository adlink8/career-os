## ⚠️ 数据时效声明(KNOW-03 核心)

**本目录任何具体薪资数字**:
1. 必须标注数据来源 + 调研日期
2. skill 调用时应触发 WebSearch 获取最新行情
3. 数字仅供量级参考,不作为谈判唯一依据

## 资料来源(优先级)

| 来源 | 类型 | 时效 |
|------|------|------|
| **实时招聘 JD(Boss/拉勾/智联)** | 一手 | 实时(最可靠) |
| **Levels.fyi** | 社区(外企为主) | 周更 |
| **看准网 / 职级茶水间** | 社区(中文) | 月更 |
| **脉脉职言** | 社区(匿名真实) | 月更 |
| 各城市人社局工资指导价 | 官方 | 年更 |
